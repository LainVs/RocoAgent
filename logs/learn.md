## 二、关键机制

### PvP 平衡（最重要）
```
提示：「精灵等级，星级，属性已做平衡性显示」
实测：每项能力值 +60（生命 510(+60)、物攻 211(+60)…）
结论：不能按种族值算伤害，必须读游戏显示的数字
```

### 命中反馈
```
克制    命中目标时飘白色「克制」字样（200%/300%）
抵抗    技能图标左上角红色向下箭头（出招前可见）
伤害    技能图标右下角数字，绿=正常，红=被抵抗
```

### 能量
```
满 10 颗星，首次入场满
用光后按 F 聚能，回 5 点
能量不足时技能图标变暗
```

### 换人与首领化
```
换人    E → 数字 → 空格
首领化  W → 1 → 空格（仅首领血脉：音速犬、白金独角兽）
```
