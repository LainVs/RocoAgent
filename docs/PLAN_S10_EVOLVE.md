# S10 计划：进化之力（首领化）

> 权威源：TapTap「首领化盘点」（25 只）、773 攻略（火神→烈火战神详细
> 数值）、rocoduel 图鉴、species 表（首领形态已入库）。

## 官方原文（多方一致）

1. **触发条件**：首领血脉的精灵 + 战斗中使用【进化之力】→ 当场首领化
2. **次数限制**：进化之力每场战斗最多 1 次（773 攻略明确）；
   愿力强化不能对首领血脉使用（rocoduel）
3. **首领化效果**（773 火神实测数据）：
   - 种族值提升：火神 636 → 烈火战神 714（+9.17%；有效值 587→624 +6.30%）
     —— 具体：生命 124 不变、物攻 156→193（+23.7%）、防御不变、速度不变
   - **特性改变**：助燃（火系技能后双攻+20%，换下清除）
     → 爆燃（火系技能后双攻**永久**+30%，换下不清除）
   - 首领化回合精灵被视为进场（配合「入场」特性的时机）
4. **形态映射**：迪莫按血脉分支——圣光（光）/圣草/圣火/圣水；
   火神 → 烈火战神；每只首领化精灵的形态是**独立 species 行**
   （圣光迪莫 5025 total=667、烈火战神 5017 total=672 已入库）
5. 部分精灵激活「远古血脉」（附加效果，暂无数据，标注不做）

## 实现方案

- **映射表** `data/leader_forms.json`：
  `{"迪莫": {"光": "圣光迪莫", "草": "圣草迪莫", "火": "圣火迪莫",
    "水": "圣水迪莫"}, "火神": {"首领": "烈火战神"}, ...}`
  先录 25 只中种族值已入库的（species 表 5017/5025 等），
  其余（impl=0 / total=0 的 25 只首领-XXX 行）列 TODO
- **Battle.magic_state 复用**：进化之力也是共鸣魔法槽的一个选项，
  但次数 = 每场 1 次（独立于愿力强化的 2 次）
- **首领化动作**（step 内）：
  1. 校验：pet.bloodline 对应形态存在 + 未用掉 1 次次数
  2. 换 species 数据：base 种族值 → 重算六维（同 iv/nature/invest）
  3. 换特性：新形态的 trait（爆燃等）→ trait_atk_buff 重算
  4. HP 按比例保留（首领化不回血——🟡 假设：原文未提回血）
  5. 广播事件「XX 首领化 → YY！」
- **ENEMY_LOSE_ENERGY 时机**（首领化被视为进场）：触发
  ON_ENTER 时机（nrc trait_fire），与换人一致

## 待确认（🟡 假设，写测试时按假设走）

  但战斗中临时形态保持原 moves（🟡 假设，原文未提当场换技能）

## 测试（src/test_s10_evolve.py）

1. 火神 血脉=首领 + evolve → 烈火战神（total 636→672，物攻 +23.7%）
2. 特性 助燃 → 爆燃（换下不清除——留到换人测试）
3. 每场 1 次；第二次 evolve 落空
4. 非首领血脉 → 落空
5. 迪莫 光血脉 → 圣光迪莫（裁决特性生效）
6. 首领化当回合照常出手
7. 愿力强化对首领血脉精灵 → 落空（rocoduel 原文）

## 基线风险

基线队伍无首领血脉配置、无 evolve 动作 → 基线零变化。

## 范围

- 本批：进化之力 + 首领化 + 形态映射（数据齐的精灵）
- 不做：远古血脉（无数据）、首领信物装备层（配置层由 cfg
  bloodline="首领" 承担）
