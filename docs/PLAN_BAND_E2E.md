### 2. 槽位是否正确（需目视取证）

| 音速犬 | 火云车 | 一致 | ✅ 铁证 |
| 冰钻布鲁斯 | 先发制人 | 暗突袭 | ？ |

前两只是**完全一致**的，说明槽位映射机制本身是对的（否则不可能
3/3 全中）。后三只的差异只有两种解释：

- (a) 用户实机换过技能，表过期 —— 那么 BAND 是对的
- (b) 槽位错位 —— 那么这几条是错的

必须用 `--band-dump` 的落盘图目视区分。判据：
**图中胶囊下方的技能名，与日志里该槽位记录的名字是否一致。**

    ['band','band','band','team_db']   -> 3 个槽位用了 BAND

已观察到 19 次这种组合，但要确认**同一局里 band 来源的槽位与
实际打出的技能对得上**（`skills` 字段里有 dmg）。

## 执行步骤

1. 用 `--band-dump` 重启（单独起 robot，不走 supervisor）
2. 打几局，等 band_dump 积累 >10 组图
3. 逐组目视核对：胶囊下名字 == 日志槽位名
4. 若吻合 -> 结论是"配置过期"，产出 `team_audit` 建议
5. 若不吻合 -> 修槽位映射
6. 恢复 supervisor 常态运行
