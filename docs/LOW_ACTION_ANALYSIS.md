不是机器人卡死，是对局本身短（对面秒投或运气局）。

## 'GATE read not stable' 的分布

与 08 点的 3 场低动作局时间重合——**技能栏读数抖动确实在吃决策窗口**，
但 STABILIZER + 3 秒 bypass 已把它兜住（多数 3 秒后成功出招）。

## 结论

1. **104 场低动作 ≠ 104 场故障**：16 场是幻影计数（重启残留），
   14 场是真实短局（对面快投），实际"卡死"比例比表面低得多。
2. **真正的损失源**：A 类幻影局污染了胜率分母 —— 夜报的"210 场"
   应该剔除幻影局再算动作率。
3. 值得做的小修：MATCH START 在 battle=False 的帧里不算数
   （要求 live 证据已存在，但 0 血进场那帧的 battle=True 是上一局
   残留 → 应该把 START 的判据再加一条：me_pct>0 或非换人面板）。
