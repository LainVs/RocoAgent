## 发现 1：伤害公式正确（无状态行验证）

比值直方图（card / base，base = power×atk/dfn×0.5）在干净的倍数上聚集：

```
{1.0: 4, 1.25: 7, 1.5: 2, 2.0: 11, 3.0: 4, 4.0: 3}   （61 行中 31 行）
```

- 1.25 = STAB（本系加成）
- 2.0 / 4.0 = 属性克制倍数
- 1.0 = 无克制无本系

**结论**：`伤害 = power × atk / dfn × 0.9 × STAB × 克制`（calc_damage
的 roco 公式）与游戏卡牌预览一致——公式层无 bug。

## 发现 2：卡牌预览含实时战斗状态

`calc_damage`（含 STAB/克制）后 MAE 反而更大（146），最差行：

```
冰钻布鲁斯→毛毛 暗突进: sim 694  card 52   （13.3×）
银月狼王→尖嘴狐仙 岩脉崩毁: sim 905  card 360 （2.5×）
```

归因：卡牌预览是**战斗中实时计算**的，包含守方当场的减伤印记/
防御增益/灼烧易伤等状态。毛毛这类坦克实战中挂着大减伤，静态面板
（species 种族值）无法复现。

**结论**：精确对账需要**战斗状态回放**——把 turns.jsonl 的每回合
动作灌回 Battle 重放，让模拟器自己积累增益/减益/印记，再对比伤害。
这是 S18b 的正确路径。
