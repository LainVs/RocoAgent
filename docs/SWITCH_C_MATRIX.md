# SWITCH_C_MATRIX — 换人决策的收益矩阵与离线验证

> 范围：只做**收益矩阵的定义与归一化、换人行的特殊性、求值准则、离线验证、灰度**。
> 不含具体阈值常数、不含实现在线代码、不含搜索树设计。
> 记号沿用 `SWITCH_A_INFO.md`（`M`/`F` 上标、`H` 比例、`h` 绝对值、`E` 能量、`Mag` 魔力）。
> **命名冲突声明**：`SWITCH_A_INFO` 用 `s_t` 表示换人指示（∈{0,1}），本文件**不复用该符号**，
> 状态一律记作 `z_t`。下文 `s` 只出现在 `s.t.`（约束）与个别局部说明里，不指代状态。
> 依据标注：`[推导]` = 由已确认事实数学推出；`[经验]` = 实战/数据观察，非严格；`[待验证]` = 假设，需实测或日志确认。

## 0. 前提、硬假设与它们带来的后果

### 0.1 三条硬假设

| ID | 假设 | 来源 | 一旦不成立的影响 |
|---|---|---|---|
| **A1** | 结算确定性：给定 `(z, a, b)`，除速度完全相同时的 1 bit 掷币外，结果唯一 | 已确认 | 矩阵需对分布求期望，而非常数 |
| **A2** | 完全信息：`z` 中所有量（双方面板、血量、能量、技能集、buff）可观测 | 设计目标 | 在线退化为估计，见 §0.3 |
| **A3** | 同时出招：双方在互不知晓对方本回合选择的情况下定稿 | 已确认 | 若不成立，§5 的无偏估计地基崩塌 |

### 0.2 三条假设直接推出三个结构性结论（后续全篇依赖）

**P0-a（随机性只有 1 bit）** `[推导]`
A1 ⇒ 矩阵单元里唯一的随机源是"优先级相同、无应对、速度相同"时的掷币。
所以 `E[M]` 不是对连续分布的积分，而是**两点凸组合**（§1.2 命题 P1）。这使求值成本比一般矩阵博弈低一个量级。

**P0-b（伤害矩阵可预计算，只依赖 4×6）** `[推导]`
`D^M(a, b)` 只通过 `(a 的威力/应对倍率, b 指定的防守方)` 进入：对手 10 个行动里，换人行动各自指定一个上场者，非换人行动都指向"当前出战者"。
⇒ 我方 4 个技能 × ≤6 个可能的防守方 = **≤24 个伤害数**，对面同理 ≤24。整个 10×10 矩阵是一次 48 项查表 + 100 次算术，不是 100 次伤害公式（§4.3）。

**P0-c（一步收益可无偏事后评估）** `[推导，条件 A3]`
A3 ⇒ 给定 `z_t`，对手的手 `b_t` 与我们的手 `a_t` 独立。因此事后用**已实现的 `b_t`** 去评估任意 `a` 的收益 `M[a][b_t]`，与反事实评估是同一分布下的样本 ⇒ 一层指标无偏（§5.2 命题 P5）。这是"离线验证"能在不掷骰子的游戏里做起来的唯一原因。

### 0.3 与在线现实（`SWITCH_A_INFO` 的 G1–G12）的接口

矩阵定义用真值，在线实现里逐项替换为估计量 `x̂`。替换后矩阵元素带误差：

```
σ_M² ≈ (w_H · σ_H)² + (w_M · σ_Mag)² + (w_E · σ_E)² + (λ · σ_V)²
```

其中血量项最大：血条 ±2% 是**相对误差**，故 `σ_H = 0.02`（与 `h_max` 无关），折算 `w_H·σ_H ≈ 0.02 HRE`；对面血量分母未知（G1）时单侧区间可达 40%，此时 `σ_M` 由**区间半宽**给出而非噪声。

**推论（贯穿全篇）**：决策可信 ⇔ `margin > 2σ_M`（§2.4）。凡 `margin < 2σ_M` 的回合，矩阵给出的两种行动在统计上不可区分，**不得用于灰度评分，也不得用于回滚归因**。

## 1. 收益矩阵构造

### 1.1 状态与动作

回合 `t` 的状态（只列进入矩阵的部分）：

```
z_t = ( i,  h^M, E^M, H^F, Mag^M, Mag^F, B^M, B^F, W, bench )
```

| 符号 | 含义 | 域 |
|---|---|---|
| `i` | 我方出战槽位 | `{1..6}` |
| `h^M` | 我方出战精确血量 | `[0, h_max^M]` 整数 |
| `H^F` | 对面出战血量**比例** | `[0,1]`（精确值受 G1 限制） |
| `E^M` / `E^F` | 能量 | `{0..10}` |
| `Mag` | 魔力 | `{0..4}` |
| `B` | buff / 印记 / 天气 | 结构化集合 |
| `W` | 可换上目标 | `⊆ {1..6}\{i}`，`\|W\| ≤ 5` |
| `bench` | 替补静态配置 + 记账血量 | 静态 + 动态 |

动作集合：

```
A^M = K_t ∪ W_t ∪ {C}        |A^M| ≤ 4 + 5 + 1 = 10
每个 k ∈ K_t 携带 (π_k, P_k, cost_k, cls_k ∈ {攻,状,防}, cnt_k ⊆ {攻,状,防} ∪ ∅)
```

`cnt_k` 是应对条件（"应对攻击/防御/状态"），∅ 表示无应对。`C` = 聚能（状态类，可被打断）。对面 `A^F` 同构，规模 `m ≤ 10`（一般 `m = 10 − 对面已阵亡数`）。

### 1.2 结算算子（三步）

#### Step 1 — 出手顺序 `u(a,b) ∈ {M, F}`

字典序比较，`ρ ~ U(0,1)` 为共享掷币（保证恰好一方先手）：

```
σ_M = ( π_a ,  c_ab ,  V^M ,   ρ  )
σ_F = ( π_b ,  c_ba ,  V^F , 1−ρ  )
u = M  ⟺  σ_M ≻_lex σ_F
```

`c_ab = 1` 当且仅当 `a` 的应对条件命中 `cls_b`，或愿力类技能的触发条件命中 `b`（愿力冲击命中状态技 → 必先手且伤害 ×2）。`V` 为速度面板。

**换人的先手位置**：默认取 `π_switch = +∞`（换人在所有技能之前结算），⚠ G7 未验证。若实际为 `π_switch = 0`，只需把该行的 `π` 改回 0，§1.2 其余部分不变（§3.5 列出两种模型的差别）。

**命题 P1（唯一随机性）** `[推导]`

```
p_tie = 1[ π_a = π_b  ∧  c_ab = c_ba  ∧  V^M = V^F ]

E_ρ[ M(a,b) ] = (1 − p_tie)·M_det(a,b)
              + p_tie · ½ · ( M^{M-first}(a,b) + M^{F-first}(a,b) )
```

`p_tie` 在实战中很小（速度面板全等且优先级全等），因此**矩阵的近确定性**成立：一个格子的值可复现，不需要 Monte Carlo。

#### Step 2 — 行动作废（关键非线性）

```
void_M(a,b) = 1[ u = F ] · 1[ D^F(b,a) ≥ h^M_t ]      # 我们这一手不发生
void_F(a,b) = 1[ u = M ] · 1[ D^M(a,b) ≥ h^F_t ]      # 对面这一手不发生

exec_M = 1 − void_M,    exec_F = 1 − void_F
```

三条结构性事实：

1. `void_M` 与 `void_F` **互斥**（同一回合只能有一方先手）。`[推导]`
2. 对**换人行**，`D(switch) = 0` ⇒ `void_F ≡ 0`（我们换人时永远无法抹除对面这一手）。`[推导]` 这是 §3 的全部起点。
3. `void` 不是"多一点伤害"，而是**乘性删除一个行动**：它把对面的整行收益置零，包括其控制/铺场/回能。线性近似会严重低估它，这正是"一击必杀 = 白赚一个回合"的数学形式。

#### Step 3 — 伤害

沿用已验证公式，其中应对/愿力只改变**乘区**，不改变公式结构：

```
base(a,def) = round( A^atk / D^def × P_a × 0.9024 )              # 先取整，不可省
D(a,b)      = round( base(a,def(b)) × 1.25^{本系} × Π_{ty∈types(def(b))} chart[type(a)][ty] × (1 − mit^def) × ζ_ab )
```

| 项 | 说明 |
|---|---|
| `def(b)` | `b` 是换人时取其上场的宠，否则取当前出战者 |
| `chart` | 解包 `type_chart` 18×18，单格 ∈ {0.5, 0.75, 1.0, 2.0}，双属性相乘 |
| 克制乘子域 | 乘积可取值集合 `{0.25, 0.375, 0.5, 0.5625, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0}`（10 个档）`[推导]` |
| `ζ_ab` | 应对成功倍率（偷袭/突袭 ×3、吹炎 ×2 等），否则 1 |
| `mit` | 减伤（防御技、印记、天气），`0 ≤ mit < 1` |

**矩阵不可分解**：`D^M(a,b)` 同时依赖 `b`（因为 `b` 决定谁挨打）与 `a`，`M` 不是 `r_a + s_b` 形式，也没有低秩近似。`[推导]` 这意味着 10×10 必须实打实算 100 格，不能省。

### 1.3 收益的五个通道

| 通道 | 符号 | 含义 | 单位 | 典型量级/回合 |
|---|---|---|---|---|
| 血量交换 | `ΔH` | 双方出战者血量比例的净变化 | HRE（§2.1） | `[-0.6, +0.6]` |
| 魔力交换 | `ΔMag` | 阵亡导致的魔力净变化 | 点 | `{-4..+4}`，实际 `{−2..+2}` |
| 能量交换 | `ΔE` | 能量**差的差** | 点 | `[-5, +1]` |
| 节奏 | `ΔT` | 被作废的**非伤害**行动的价值 | HRE | 见 §1.5 R3 |
| 局面 | `ΔV` | 回合末棋盘（含强制换人、印记、天气）的价值变化 | HRE | `[-0.8, +0.8]` |

### 1.4 完整表达式

```
                 ┌──────────────────────────────────────────────────────────────┐
                 │  M[a][b] =  w_H·ΔH  +  w_M·ΔMag  +  w_E·ΔE                  │
                 │            + w_T·ΔT  +  λ·ΔV        ( + ½p_tie 修正, P1 )    │
                 └──────────────────────────────────────────────────────────────┘

ΔH    =  q^F · min( exec_M·D^M(a,b) , h^F_t ) / h_max^F
       −  q^M · min( exec_F·D^F(b,a) , h^M_t ) / h_max^M

ΔMag  =  κ^F_trait · 1[ h^F_{t+1} = 0 ]  −  κ^M_trait · 1[ h^M_{t+1} = 0 ]      # 正 = 对我方有利

ΔE    =  ( E^M_{t+1} − E^M_t ) − ( E^F_{t+1} − E^F_t )                          # 双方每回合 +1 时自动抵消

ΔT    =  void_F · v_status(b)  −  void_M · v_status(a)
         v_status(x) = 0           若 x 为攻击/换人
         v_status(x) = v_setup(x)  若 x 为状态/铺场（天气、印记、强化）

ΔV    =  V(z_{t+1}) − V(z_t)
         V(z) = Σ_{p∈M 存活} q_p·(h_p/h_max_p) − Σ_{p∈F 存活} q_p·(h_p/h_max_p)
                + β_w·1[天气归我] + β_m·(正向印记数 − 负向印记数)
```

| 记号 | 定义 | 取值 |
|---|---|---|
| `q` | 宠物战斗价值权重 | 默认 1.0；冥古龙在等级衰减后 `q < 1`；一次性摔炮按定位下调 |
| `κ_trait` | 阵亡的魔力扣点（含特性） | 普通 1 / 诈死 2 / 赎价 0 / 飓风 0 / 御驾亲征 4；**击杀者带赎价时对方再 +1** |
| `v_setup` | 被作废铺场动作的折现价值 | 0.2–0.4 HRE，待标定 |
| `λ` | 前瞻折现 | 0 = 单步近视，0.5 = 半回合前瞻，1 = 全折现 |

**为什么不把"是否致死"直接写进 `ΔH`**：`1[D ≥ h]` 是绝对量的硬比较，而 `ΔH` 是比例。若只在比例上做文章，一个 `H^F = 0.05`、`h^F = 20` 的残血宠与 `H^F = 0.95`、`h^F = 380` 的满血宠在比例尺上一视同仁，但前者一击线只需 20。

**规范**：**内部全部用绝对整数 HP 结算（含 `round` 与阈值比较），只在输出层归一化**。比例只用于跨宠可比，不参与判定。`[推导]`

### 1.5 防止重复计数的三条规则（矩阵自洽的全部原因）

| 规则 | 内容 | 违反后果 |
|---|---|---|
| **R1** | 溢出伤害不计分：`ΔH` 用 `min(D, h)` 截断 | 系统偏向"打高伤"而非"打得准" |
| **R2** | 击杀的奖励**只**走 `ΔMag` + `ΔV`，不在 `ΔH` 之外再加"击杀奖励" | 双重计入 ⇒ 无脑追击杀 |
| **R3** | `void` 的额外奖励只对**非伤害行动**计 `ΔT`；对攻击行动 `v_status = 0` | 双重计入 ⇒ 高估先手（伤害的抹除已在 `ΔH` 里） |

`[推导]` 三条规则来自"每个资源只在唯一通道里计一次"的分解原则；R2 与 R3 是本文档最容易写错、也最影响策略性格的两处。

### 1.6 矩阵形态（10×10 的块结构）

```
               对面 b
        技能×4    聚能    换人×5
       ┌─────────┬─────────┬─────────┐
  技能 │    A    │    B    │    C    │
  聚能 │    D    │    E    │    F    │
  换人 │    G    │    H    │    I    │
       └─────────┴─────────┴─────────┘
```

| 块 | 结构 | 关键点 |
|---|---|---|
| **A** 技能×技能 | `ΔH` 双向、`ΔMag` 可能非零 | 只有先手方可能击杀；`void` 只在这里出现 |
| **B** 技能×聚能 | 我们必打断（攻击类打断状态类） | `void_F` 常为 1；`ΔT = v_setup(聚能)`——聚能被废是纯赚 |
| **C** 技能×换人 | 伤害打在**换上者**身上（含其属性/防御） | 需要 `b` 的目标参与 `D`；这是"读换"的全部价值 |
| **D** 聚能×技能 | 我们被打断，`void_M` 常为 1 | 高风险行；PVP_NOTES 的"绝不聚能"就是这一行的经验版 |
| **G/H** 换人×技能/聚能 | `ΔH` 只有我方挨打，`ΔMag` 可能为负（新宠被秒） | 对面这一手**必然发生**（命题 P2） |
| **I** 换人×换人 | `ΔH = 0`，只走 `ΔV` | 纯位置交换；双方都不掉血 |

### 1.7 一个数值算例（示例数值，非实测；仅演示量纲）

```
状态：恶魔狼 h^M = 417，对面一击 D^F = 180
      我方最优技能对当前对手 145，对面 h_max^F = 400
      替补 k：h_max = 350，对同一次攻击的类型乘子 = 0.5 ⇒ 承伤 90

留场：ΔH = +145/400 − 180/417 = +0.363 − 0.432 = −0.069
换 k：ΔH = 0          −  90/350 = −0.257
      （ΔMag = 0，ΔE = 0，ΔT = 0 —— 我们这手没有作废任何东西）

差值：留场 − 换人 = +0.188 HRE
```

**读法**：单步意义上留场更好 0.188 HRE；换人必须从 `λ·ΔV` 里补回 ≥ 0.188 才成立（§3.3）。

## 2. 矩阵归一化

### 2.1 单位制：HRE

定义 **1 HRE = 一只满血标准宠的血量**（约 400 HP，取六只的中位 `h_max`）。所有通道折算到 HRE：

| 通道 | 原始单位 | 折算 | 默认权重 | 理由 |
|---|---|---|---|---|
| `ΔH` | 比例 | 恒等 | `w_H = 1.0` | 基准单位，定义即 1 |
| `ΔMag` | 魔力点 | `w_M` | `1.2`（区间 0.8–1.8） | 见 §2.2 |
| `ΔE` | 能量点 | `w_E` | `0.20`（区间 0.10–0.30） | 见 §2.2 |
| `ΔT` | HRE | 恒等 | `w_T = 1.0` | 已经折算过，`v_setup` 内含价值 |
| `ΔV` | HRE | 恒等 | `λ ∈ {0, 0.5, 1}` | 折现，不是价值权重 |

### 2.2 权重推导

**`w_M ≈ 1.2`** `[推导 + 待验证]`

两种锚定法给出不同答案，差别本身就是敏感性的来源：

| 锚定法 | 算法 | 结果 |
|---|---|---|
| 资源总量法 | 4 点魔力 ↔ 6 只宠的 600% 血池 ⇒ 1 点 = 1.5 HRE | 1.5 |
| 边际交换法 | 一只宠阵亡 = 1 点魔力 + 该宠剩余战斗价值；在"摔炮互爆"的实战节奏里，击杀的实际边际价值低于资源总量比 | 1.0–1.3 |

取 `1.2` 为中位。**注意 R2**：`ΔH` 里已扣掉那 100% 血量，`w_M` 只是"魔力账本"的额外价值，不是宠物的全部价值。

**`w_E ≈ 0.20`** `[推导]`

能量不是资源，是**期权的行权价**。边际价值 = 让最高威力技能多用一次所多出的伤害：

```
多 1 点能量 ⇒ 多打 1 发 k 费技能
边际伤害 = D(最优 k 费技) − D(次优 (k−1) 费技)  ≈ 0.15~0.30 HRE
```

PVP_NOTES 的"4–5 费打两发就哑火、聚能被地刺打断"是同一件事的代价形态：能量耗尽的惩罚不是"少打一下"，而是"被迫进入高风险行 D"。这条经验使 `w_E` 略高于纯伤害差（0.15 → 0.20）。

**`v_setup ∈ [0.2, 0.4]`** `[经验]`
被作废的天气/印记，其价值 ≈ 一个回合的对手输出量级（0.3 HRE）。沙武队"开天气"被我们打断时，我们赚的不是血量而是整个引擎延迟 1 回合。

### 2.3 魔力通道的凸性

线性 `ΔMag` 假设"第 1 点与第 4 点等价"，但 `Mag = 1` 时任何阵亡即负 ⇒ 风险偏好必须随 `Mag` 变化。`[推导]`

用**紧迫系数**替代线性：

```
ΔMag_eff = − ρ(Mag^M)·ΔMag⁻ + ρ(Mag^F)·ΔMag⁺     # ΔMag⁻ = 我方损失量(≥0), ΔMag⁺ = 对方损失量(≥0)
ρ(m) = 1 + γ·(4/m − 1),   γ = 0.15

m=4 → 1.00    m=3 → 1.05    m=2 → 1.15    m=1 → 1.45
```

理由：`m=1` 时一次普通阵亡即终局，损失的边际效用是 `m=4` 时的 ~1.45 倍。`γ` 取 0.15 使 `m=1` 的风险溢价约 45%，与"1 点魔力 = 25% 胜负资源"的线性期望接近但略偏保守。`[待验证]`：`γ` 应由 §5 的日志拟合确定，不是拍的。

### 2.4 敏感性：翻转阈值（本文档的鲁棒性检验）

两个行动 `a₁, a₂` 的决策在权重 `w` 变化下翻转的临界点：

```
M(a₁) − M(a₂) = w_H·ΔΔH + w_M·ΔΔMag + w_E·ΔΔE + w_T·ΔΔT + λ·ΔΔV

w*  =  −( w_H·ΔΔH + w_E·ΔΔE + w_T·ΔΔT + λ·ΔΔV ) / ΔΔMag
```

**判据**：若 `w*` 落在 `w_M` 的合理区间 `[0.8, 1.8]` **之外**，该决策对权重不敏感（鲁棒，可上线）；若落在区间**之内**，决策由权重猜测决定（脆弱，不得上线，或必须先把 `w_M` 标定到 ±10%）。

算例（续 §1.7）：

| 情形 | `ΔΔMag` | `w*_M` | 结论 |
|---|---|---|---|
| 换人后下回合能击杀 | +1 | 0.19 | 鲁棒（远低于 0.8） |
| 换人只多拖一点血 | +0.1 | 1.88 | 脆弱（落在区间边缘） |
| 换人导致新宠被秒（`ΔΔMag = −1`） | −1 | −0.19 | 鲁棒地**不换** |

`[推导]` 这张表说明：**换人决策的鲁棒性几乎完全由"换上去能不能活/能不能杀"决定，而不是由精细的血量差决定**。这与 `SWITCH_A_INFO` §3 的"★★★ 三项"一致。

### 2.5 权重标定（唯一可证伪来源）

所有权重都不该拍脑袋，应从日志拟合：

```
logit P(win) = θ₀ + θ_H·ΔH_cum + θ_M·ΔMag_cum + θ_E·ΔE_cum
⇒  w_M/w_H = θ_M/θ_H,   w_E/w_H = θ_E/θ_H
```

在 §5 的单步无偏数据集（命题 P5）上做逻辑回归，用**比值**而非绝对值，消除标度自由度。`[待验证]`：需要 ≥500 个已标注回合（§5.3）才能把 `θ_M` 的 95% CI 压到 ±15%。

## 3. 换人这一行的特殊性

### 3.1 与技能行的逐项差异

| 维度 | 技能行 | 换人行 | 后果 |
|---|---|---|---|
| 本回合伤害 | `D ≥ 0` | **恒为 0** | 无法击杀，无法滚雪球 |
| 能否作废对面 | 可能（先手击杀） | **不可能**（命题 P2） | 对面这一手 100% 落地 |
| 对面伤害落点 | 我方当前出战者 | **换上者**（若 `π_switch = +∞`） | 承伤由新宠的属性/防御决定，可能更疼 |
| 先手序 | 参与 `π/V` 比较 | 通常 `+∞`，必先结算 | 不参与博弈，是一个"元动作" |
| 能量 | 消耗 `cost_k` | 不消耗；切换到另一条能量池 | `ΔE` 是**池的切换**，不是花费 |
| 印记 | 可能新增/清除 | **不清除**（换人不消印记） | 换走 ≠ 洗白，只放弃该宠身上的收益 |
| 新宠阵亡风险 | — | 若 `D^F ≥ h_k` ⇒ 立即 `ΔMag` 负 | 换人可能直接送 1 点（诈死宠送 2 点） |
| 对类型乘子场 | 无影响 | **唯一能改变后续乘子的动作** | 见命题 P3 |
| 单步收益 | 可正可负 | **在对手攻击时几乎必为负** | 见命题 P2 |

### 3.2 换人行的表达式

对 `a = switch(k)`：

```
ΔH(a)   = − q^M · min( D^F(b, k) , h_k ) / h_max^k        # 只挨打，无输出
ΔMag(a) = − κ^M_k · 1[ D^F(b,k) ≥ h_k ]  +  κ^F·1[对面本回合自爆/自杀]   # 后项通常为 0
ΔE(a)   = ( E_k − E^M_t ) − ( E^F_{t+1} − E^F_t )          # 池切换，可能为正（换进满能量的宠）
ΔT(a)   ≡ 0    # 两重原因：v_status(换人)=0；且 π_switch=+∞ ⇒ 换人不会被作废
ΔV(a)   = V(z_{t+1}) − V(z_t)                              # 唯一可能为正的通道
```

**命题 P2（换人的单步劣势定理）** `[推导]`

设对手行动为攻击类，我方技能 `a` 造成 `D^M(a,b)`，当前出战者承受 `D^F(b,i)`，换上行承受 `D^F(b,k)`。忽略 `ΔMag/ΔE/ΔT`：

```
换人优于留场  ⟺  q^F·D^M(a,b)/h_max^F  <  q^M·[ D^F(b,i)/h_max^i − D^F(b,k)/h_max^k ]
                  └──── 放弃的输出 ────┘     └──────────── 省下的承伤 ────────────┘
```

即：**放弃的输出 < 省下的承伤** 才成立。用 §1.7 的数：放弃 0.363，省下 0.432−0.257 = 0.175 ⇒ 不成立。

**这条不等式是"为什么机器人总是不换人"的完整解释**：正常对局里，"我们这一手能打掉的比例"通常大于"换人能省下的比例"，因为省下的差值只是 `D^F·(1/h_i − μ_rel/h_k)`，量级 0.1–0.2，而一手输出是 0.3–0.4。

⇒ **单步矩阵（`λ = 0`）在数学上必然导致"永不换人"**。换人的全部价值在 `ΔV` 与后续回合，必须由前瞻显式提供。

### 3.3 前瞻需求的下界

由 P2，`λ·ΔV > 0.188`（§1.7 数）才换。若 `λ = 0.5`，需 `ΔV > 0.376`。`ΔV` 的可达范围：

```
ΔV = q_k·(h_k/h_max_k − h_i/h_max_i)                   # 血量替换
   + (q_k − q_i)·1                                    # 质量替换
   + β_w·Δ天气 + β_m·Δ印记
   + 【对手被迫换人的局面价值】
```

`[经验]` 一个"属性关系反转 + 换进高质宠"的组合可达 `ΔV ∈ [0.3, 0.6]`，刚好跨过 0.376 的门槛。这说明：
- `λ = 0` ⇒ 永不换人（退化）
- `λ = 0.5` ⇒ 只在**明显**优势时换人（保守，符合灰度阶段需求）
- `λ = 1` ⇒ 频繁换人（激进，容易被读换惩罚）

**建议 `λ = 0.5` 作为默认**，理由：它把换人门限设在"半个回合的价值"上，与"换人损失半个回合的行动权"在量纲上自洽。`[推导]`

### 3.4 命题 P3（换人是元动作）

`[推导]` 只有换人行动会改变 `chart[type(·)][type(·)]` 的取值。因此：

1. 换人行是矩阵里**唯一与状态转移耦合**的行——其余 9 行的结果都由当前 `(i, j)` 决定，只有换人会改变下一回合的乘子矩阵。
2. 由此，`ΔV` 不能用"当前血量差"近似，必须含"下一回合乘子改善"的期权价值：`ΔV_opt ≈ E[D^F_新对位] − D^F_旧对位` 的折现。
3. 这也是"读换"能成立的原因：对面换人后我方技能打的是新宠（块 C），先手的换人把"打谁"从确定变成由对面选择。

### 3.5 换人规则成本清单（全部 ⚠ G7 待实测）

| 项 | 两种模型 | 对矩阵的影响 |
|---|---|---|
| 结算时机 | `π_switch = +∞` / `π_switch = 0` | 决定伤害落点是新宠还是旧宠，`ΔH` 差一个乘子 |
| 旧宠是否保留本回合承受的伤害 | 是 / 否 | 若"否"，换人可当"无伤撤退"，价值 +0.2~0.3 HRE |
| 能量归属 | 随宠保留 / 换人重置 | `ΔE` 项的符号在此翻转 |
| 印记归属 | 留在原宠 / 跟随出战位 | `ΔV` 的 `β_m` 项是否被清空 |
| 是否占用行动 | 是（本设计假设） / 否（免费换） | 若免费，P2 失效，换人永远占优 |

**判据**：只要"是否占用行动"这一项是"是"（已由"本回合伤害=0"间接支持），P2 与 §3.3 成立；其余四项只改常数，不改结构。

## 4. 求值方式

### 4.1 四种基准准则（含适用对手类型）

| 准则 | 决策规则 | 适用 | 代价 |
|---|---|---|---|
| **纯 maximin** | `a* = argmax_i min_j M[i][j]` | 对手会针对我们的固定手 | `O(nm)` |
| **混合 maximin（LP）** | `max v s.t. Σ_i x_i M[i][j] ≥ v ∀j, Σx = 1, x ≥ 0` | 对手会变、且我们可随机化 | LP，见 §4.5 |
| **期望值（均匀）** | `a* = argmax_i (1/m)Σ_j M[i][j]` | 对手完全无信息（探索期基线） | `O(nm)` |
| **贝叶斯加权** | `a* = argmax_i Σ_j P(j\|h_t)·M[i][j]` | 有历史、对手有套路（引擎型/摔炮型） | `O(nm + K)`，`K` = 类型数 |

**映射到实战对手**（PVP_NOTES §五）：

```
引擎型（沙武：天气→印记→0 费循环）  →  P(j|h) 高集中在"前 3 回合的铺场手" ⇒ 贝叶斯/最佳应对
摔炮型（互爆、拼一击线）            →  对手在"最大伤害"上近似确定 ⇒ 纯 maximin 等价于最佳应对
未知/会变                          →  混合 maximin（LP）
```

`[经验]` 三类对手的边界不清晰，实战中"未知"占多数 ⇒ 默认用 §4.3 的折中。

### 4.2 ε-污染鲁棒解（推荐默认）`[推导]`

不选纯 maximin（过度保守，会被"对手其实很菜"惩罚），也不选纯期望（会被针对）：

```
Π_ε = { P = (1−ε)·P̂ + ε·Q : Q 为 A^F 上任意分布 }

min_{P∈Π_ε} E_P[ M_i ] = (1−ε)·E_{P̂}[M_i] + ε·min_j M[i][j]
```

证明：目标对 `Q` 线性，线性函数在单纯形上的最小值必在顶点取得。∎

```
a* = argmax_i [ (1−ε)·row_mean_i + ε·row_min_i ]        # O(nm)，闭式，无需迭代
```

| `ε` | 行为 | 建议场景 |
|---|---|---|
| 0 | 纯期望（贝叶斯均匀） | 探索期、对手完全未知 |
| 0.2–0.4 | 温和保守 | **排位默认** |
| 1 | 纯 maximin | 对面明牌会针对、或高分段 |

`ε` 是本文档**唯一需要的"胆量旋钮"**，且它同时是 A/B 的一个天然实验维度（§6）。

### 4.3 复杂度

记 `n = |A^M| ≤ 10`，`m = |A^F| ≤ 10`，`c` = 单格求值成本。

| 运算 | 操作数 | 复杂度 | 说明 |
|---|---|---|---|
| 伤害预计算 | `\|K\|·\|P\|` = 4×6 | `O(\|K\|\|P\|)` = 24 | P0-b，与矩阵规模无关 |
| 建矩阵 | `nm` | `O(nm)` | 每格 ~10 次浮点 + 2 次查表 |
| 纯 maximin | `nm` | `O(nm)` | 行内 min + 行间 max |
| 期望值 | `nm` | `O(nm)` | 矩阵-向量乘 |
| ε-污染 | `2nm` | `O(nm)` | 行均值 + 行最小 |
| 混合 maximin | LP | `O((n+m)^{2.5} L)`（内点）或单纯形 `O(iter·nm)` | 10×10 时 `iter ≈ 10` |
| 虚拟对局（迭代法） | `T·nm` | `O(nm/δ²)` 达 `δ` 精度 | 仅在无 LP 求解器时用 |
| 深度 `d` 前瞻 | `(nm)^d` 格 | `O((nm)^d)` 次格求值 + `(nm)^{d−1}` 次求解 | 见 §4.4 |

### 4.4 前瞻预算

```
d=1：1 个矩阵                10² 格
d=2：nm = 10² 个矩阵         10⁴ 格
d=3：10⁴ 个矩阵              10⁶ 格   ← 超过 15 s 回合预算
d=4：10⁶ 个矩阵              10⁸ 格
```

单格成本 `c` 的三档估计（CPython 3.11，含 dict 查表）：

| 实现 | `c` | 依据 |
|---|---|---|
| 预计算伤害表 + 局部变量 | 1.5–2 µs | 24 个数查表 + 算术 |
| 每格重算伤害公式 | 8–15 µs | 含 `round`×2、属性表嵌套查 |
| 含 buff/印记动态乘区 | 20–40 µs | 每格多次分支 |

总耗时（只算格求值，不含每节点的求解器）：

| `d` | 格数 | @2 µs | @15 µs | @30 µs | 15 s 内可行？ |
|---|---|---|---|---|---|
| 1 | 10² | 0.2 ms | 1.5 ms | 3 ms | ✅ 余量巨大 |
| 2 | 10⁴ | 20 ms | 150 ms | 300 ms | ✅（+ 100 次 LP ≈ 50 ms） |
| 3 | 10⁶ | 2 s | 15 s | 30 s | ❌（+ 10⁴ 次 LP ≈ 5 s） |
| 4 | 10⁸ | 200 s | — | — | ❌ |

LP 单次（scipy/HiGHS）：0.3–0.8 ms；纯 Python 单纯形：1–3 ms。`d=3` 时每节点解一次 LP ⇒ `10⁴ × 0.5 ms = 5 s`，**LP 成为瓶颈而非矩阵构造**。

**结论**：实用上限是 `d = 2`（矩阵 + 一层 rollout，约 0.1–0.4 s）。`d = 3` 只在两种情况下可用：预计算伤害表（`c = 2 µs`）**且**用 α-β / 局面粗筛把节点数从 `10⁴` 砍到 `10³` 以下。默认 `d = 2`。`[推导]`

### 4.5 实际耗时估算汇总（单回合决策）

| 方案 | 组成 | 估算 |
|---|---|---|
| 纯 maximin，`d=1` | 建矩阵 0.5 ms + 扫描 0.01 ms | **~0.5 ms** |
| ε-污染，`d=1` | + 2×100 运算 | **~0.5 ms** |
| 混合 LP，`d=1` | + 0.3–0.8 ms | **~1 ms** |
| 贝叶斯，`d=1` | + 后验更新（K≤8） | **~0.6 ms** |
| LP，`d=2` | 100 节点 × (0.5+0.5) ms | **~0.1 s** ✅ |
| LP，`d=3` | 10⁴ 节点 × 1 ms | **~10–15 s** ❌ |

对照回合预算 15 s 与 `SWITCH_A` 的采集耗时 1.56 s（方案 C）：**求值本身不是瓶颈，采集与前瞻深度才是**。

### 5.2 三层指标

#### 层 1 — 一步收益（无偏，低方差）

**命题 P5** `[推导，条件 A3]`

同时出招 ⇒ `b_t ⊥ a_t | z_t`。因此对任意策略 `g`：

```
Δ_t(g) = M[ g(z_t) ][ b_t ] − M[ a_t ][ b_t ]
E[ Δ_t ] = E_z[ E_b[ M[g(z)][b] − M[a][b] ] ]        ← 对 b 取期望，与 a、g 无关
```

即：**用已实现的对面手 `b_t` 同时评估"建议手"和"实际手"，差值是无偏的策略优势估计**。不需要反事实，不需要随机化，不需要模拟器。

| 指标 | 定义 | 期望 | 用途 |
|---|---|---|---|
| `Δ_t` | 上式的逐回合值 | > 0 = 判据更优 | 主指标 |
| `Δ̄` | `mean(Δ_t)`，按 `battle_id` 聚类 | — | 判据总体优势 |
| `hit_t` | `1[Δ_t > 0]` | 0.5 为无效 | 稳健版（抗离群） |

**注意**：这要求 `M` 的估计误差 `σ_M` 小于 `Δ_t` 的量级，因此必须按 `margin > 2σ_M` 过滤（§0.3）。`[推导]`

**样本量**：`Δ_t` 是连续量，`σ_Δ ≈ 0.2 HRE`，检测 `δ = 0.05`：

```
n = (z_{0.975} + z_{0.8})² · σ_Δ² / δ²  =  7.849 × 0.04 / 0.0025  =  126
```

**126 个决策点即可** —— 这是所有方案里最便宜的一层，应作为第一优先级。

#### 层 2 — k 步结局（有偏但贴近决策，`k = 2`）

```
Y_t^{(2)} = Mag^M_{t+2} − Mag^M_t        （我方净损失，越负越好）
         或 存活数差、2 回合后血量差、是否崩盘（2 回合内损失 ≥2 点）
```

| 指标 | 定义 | 优点 | 偏差来源 |
|---|---|---|---|
| 净魔力差 | `ΔMag[0,2]` | 与胜负资源直接挂钩 | 状态选择偏差 |
| 崩盘率 | `1[ΔMag ≤ −2]` | 二值，好讲 | 稀有事件，方差大 |
| 追击死亡 | 换入者 1 回合内阵亡 | 直接对应"失败 2" | 只覆盖换人子集 |

**偏差来源与对策**：判据恰好在"坏状态"触发 ⇒ 直接比较"建议换"与"建议不换"两组等于比较两种状态。
必须**匹配**：在同一 `(species^M, species^F, H^M 分箱, H^F 分箱, Mag 差, E^M 分箱)` 内做配对，或对状态做倾向得分 `e(z) = P(g(z)=SWITCH | z)` 的分层。`[推导]`

#### 层 3 — 对局级（最终标准，最贵）

`win_rate(g) − win_rate(baseline)`。需要 §5.3 的完整样本量，且受 `Δ` 的间接性影响（胜率是长期结果，单回合决策的信号被稀释）。

**三层的关系**：

```
层 1（126 个决策点，无偏，1 步）→ 快速筛掉明显错的判据
层 2（~700 个决策点，匹配后，2 步）→ 确认"短期不亏"
层 3（~350 局/臂）→ 确认"长期赢"
```

### 5.3 样本量估算

#### 公式

两比例（独立，`α = 0.05`，power `= 0.8`，`z_{0.975}=1.96`，`z_{0.8}=0.8416`）：

```
n_arm = (z_{1−α/2} + z_{1−β})² · [ p₁(1−p₁) + p₂(1−p₂) ] / (p₁ − p₂)²
      = 7.849 · [p₁(1−p₁) + p₂(1−p₂)] / δ²
```

连续量（均值差）：

```
n_arm = 2(z_{1−α/2} + z_{1−β})² · σ² / δ²  =  15.70 · σ²/δ²
```

配对（同一状态两行动，用差值方差 `σ_d`）：

```
n_pairs = (z_{1−α/2} + z_{1−β})² · σ_d² / δ²  =  7.849 · σ_d²/δ²
```

聚类校正（回合嵌套于对局）：

```
DEFF = 1 + (m̄ − 1)·ρ           m̄ = 每局决策点数, ρ = 局内相关系数
n_turns = n × DEFF / π_opp      π_opp = 回合中真正构成换人决策点的比例
```

#### 数表

| 目标 | 指标类型 | `p₁ / p₂` 或 `σ` | `δ` | `n/臂` |
|---|---|---|---|---|
| 崩盘率 20%→30% | 比例 | 0.20 / 0.30 | 0.10 | **290** |
| 崩盘率 10%→15% | 比例 | 0.10 / 0.15 | 0.05 | **683** |
| 胜率 50%→60% | 比例 | 0.50 / 0.60 | 0.10 | **385** |
| 胜率 50%→55% | 比例 | 0.50 / 0.55 | 0.05 | **1562** |
| 一步优势 `Δ_t` | 连续 | `σ_Δ = 0.20` | 0.05 | **126**（配对） |
| 2 回合魔力差 | 连续 | `σ = 0.30` | 0.05 | **565** |

`[推导]` 全部由上式代数得出。

#### 实战折算

取"崩盘率 20%→30%"（`n = 290`），并校正聚类与稀有性：

```
m̄ = 8 回合/局, ρ = 0.2      ⇒ DEFF = 1 + 7×0.2 = 2.4
π_opp = 0.25（只有 1/4 的回合是真正的换人机会）

n_turns  = 290 × 2.4 / 0.25 = 2784 回合/臂
n_battle = 2784 / 8         = 348 局/臂
时长     = 348 × 3 min      ≈ 17 h/臂   （两臂 34 h）
```

`[经验]` `m̄`、`ρ`、`π_opp` 是估值，需从 §5.1 的日志先算出来；`m̄` 和 `π_opp` 完全可由现有日志统计得到，`ρ` 需要至少 50 局。

**结论**：层 3 的 A/B 成本是**周级**，因此灰度必须分阶段（§6），不能一上来就跑全量对照。

### 5.4 反事实的困难与可行替代

#### 为什么难

| 困难 | 本质 | 后果 |
|---|---|---|
| **D1 确定性** | 同一 `(z,a)` 只观测一次，没有重复采样 | 无法用"同一状态多次试"估计 `Q(z,a)` |
| **D2 状态不可复现** | 换人后局面偏离，后续观测属于"另一个世界" | `Y^{(k)}` 的两条分支只有一条可见 |
| **D3 隐藏状态** | 对面面板/血量区间（G1/G2） | `M` 本身带误差，反事实的目标函数就是模糊的 |
| **D4 策略内生** | 我们自己的策略在灰度期变化 | 前后期样本不可直接合并 |
| **D5 对手适应** | 同一对手会调整 | 长期 A/B 的"同一分布"假设被破坏 |

#### 五种替代，按可信度排序

| # | 方法 | 估计量 | 偏差 | 方差 | 前提 |
|---|---|---|---|---|---|
| **M1** | **模拟器 rollout** | `M̂[g(z)][b] + λ·V(rollout)` | 中（模拟保真度） | 低 | 伤害确定性 + 状态基本可观测 |
| **M2** | **一步已实现对手手**（命题 P5） | `Δ_t` | **零**（在 A3 下） | 中 | `b_t` 已记录、`σ_M` 小 |
| **M3** | **随机化探索**（ε-greedy，`ε=5–10%`） | IPS / DR | 零（无偏） | 高 | 敢在实战里故意做次优动作 |
| **M4** | **影子策略**（只算不动） | 一致率 `P(g(z)=a)` | **不是正确性** | 低 | 无 |
| **M5** | **匹配结局比较** | 层 2 指标 | 中（残余混杂） | 中 | 足够样本 + 匹配变量齐 |

**M4 的陷阱必须写死**：影子策略只能回答"判据会不会改变行为"，**不能**回答"改变得对不对"。把它当正确性证据是本文档最容易犯的方法论错误。

**M1 的保真度闸门**：逐回合重放，比较模拟器预测的下一状态与日志：

```
fidelity = P( |ĥ_pred − ĥ_obs| ≤ 1 )          按回合
```

只在 `fidelity ≥ 0.90` 的子集上采信反事实；低于此值的局面（多为 G1/G2 估计区间过宽）标记为"不可评估"。

**M3 的代价核算**：`ε = 0.05` 的探索在 20 回合的对局里损失约 `1 − 0.95^{20} ≈ 64%` 的对局至少吃一次次优手，胜率损失估计 1–3 pp。`[经验]` 这是灰度期可接受的学费，也是唯一能拿到无偏 `Q` 的途径。

### 5.5 失效模式清单（评估本身会错的地方）

| 失效 | 表现 | 检测 | 处置 |
|---|---|---|---|
| **F1 后见之明** | 用 `argmax_a M[a][b_t]` 当"最优"，任何策略都显得差 | `Δ_t` 恒为负 | 只比较 `g(z)` 与 `a`，不比较"上帝视角最优" |
| **F2 测量误差吞掉信号** | `margin < 2σ_M` 的回合占比高，`Δ̄` 的 CI 覆盖 0 | 统计 `margin` 分布 | 过滤低 margin 回合；报告过滤前后两版 |
| **F3 聚类低估方差** | CI 过窄，假阳性 | 用 `battle_id` 做 cluster bootstrap | 一律用聚类稳健标准误 |
| **F4 状态漂移** | 版本升级后对手分布变了 | 按周分箱看基线胜率 | 分段归因，不跨版本合并 |
| **F5 同时性被破坏** | 若游戏在对面定稿前展示我方换人动画 | `P(对面针对我方换人) > 基线` | 检验：换人回合的对面前一手技能分布是否异常 |
| **F6 模拟器自证** | 用同一份代码既生成标签又做评估 | — | 至少留 20% 日志做留出集 |

**F5 的检验方法** `[待验证]`：若同时性成立，则 `P(b_t = 克制换上者 | a_t = switch(k))` 应等于 `P(b_t = 克制 k | a_t = 其他)`。若显著不等，A3 破裂，命题 P5 失效，验证方案必须整体退回到 M3/M5。

## 6. A/B 落地（不影响真实排位）

### 6.1 四阶段

| 阶段 | 行为 | 曝光条件 | 时长/样本闸门 | 产出 |
|---|---|---|---|---|
| **S0 影子** | 只算 `g(z)`、写日志，从不执行 | 全部对局 | ≥ 300 个决策点 | `margin` 分布、一致率、耗时分布 |
| **S1 低风险启用** | 仅在"高置信 + 高缓冲"时执行 `g(z)` | `margin ≥ 0.30 HRE` **且** `Mag^M ≥ 3` **且** 双方存活 ≥ 5 | ≥ 120 个执行样本 | 层 1 `Δ̄` |
| **S2 扩大** | 放宽到中等风险 | `margin ≥ 0.15` **且** `Mag^M ≥ 2` | ≥ 300 个执行样本 | 层 2 指标 |
| **S3 全量** | 无额外门限 | 全部 | ≥ 350 局/臂 | 层 3 胜率 |

**S1 门限的理由** `[推导]`
`margin ≥ 0.30` ⇒ 决策不是权重噪声的产物（§2.4）；
`Mag^M ≥ 3` ⇒ 单次错误最多损失 1 点，不改变对局定性；
存活 ≥ 5 ⇒ 处于局面早中期，`ΔV` 的可恢复性最高，错误不至于被终局放大。

### 6.2 随机化（否则没有对照臂）

影子期**只有处理组**，无法做因果。S1/S2 必须在同一门限内做 Bernoulli 随机：

```
对每个满足门限的决策点：以 p = 0.5 执行 g(z)，否则执行基线策略
```

**这是唯一能给出无偏处理效应的设计**。若产品上不能接受随机（例如随机会让胜率波动），退化为 M3 的 ε-greedy（`ε = 0.05`），代价是层 2/3 的样本量 ×4。

**分层随机**：按 `(Mag^M, margin 分箱)` 分层，保证两臂状态分布一致。`[推导]`

### 6.3 回滚判据

#### 6.3.1 为什么"连续 N 次错误"是弱判据

若真实错误率 `p = 0.10`（可接受），300 个决策点中出现"连续 3 次错误"的概率：

```
P(至少一段 run ≥ 3) ≈ 1 − exp( −298 × 0.1³ ) = 1 − e^{−0.298} ≈ 26%
```

`[推导]` ⇒ 固定 `N=3` 的规则在**判据其实合格**时有约 26% 的概率误触发回滚。样本越多越必然触发。**必须用序贯检验，不用连击计数。**

#### 6.3.2 SPRT（主判据）

定义"错误决策" `ℓ_t = 1` 当且仅当满足任一：

```
E1  M[g(z_t)][b_t] < M[a_t][b_t] − 0.20 HRE        （层 1，事后可算）
E2  换入者在本回合或下回合阵亡                        （直接对应"失败 2"）
E3  该决策导致净损失 ≥ 2 点魔力                       （灾难级）
```

SPRT（`H₀: p = 0.10` 可接受 vs `H₁: p = 0.20` 不可接受，`α = β = 0.05`）：

```
Λ_t = Λ_{t−1} + log( p₁/p₀ )           若 ℓ_t = 1  → +0.693
             + log( (1−p₁)/(1−p₀) )   若 ℓ_t = 0  → −0.118

接受 H₁ → 回滚      当 Λ_t ≥ log( (1−β)/α ) = +2.944
接受 H₀ → 继续      当 Λ_t ≤ log( β/(1−α) ) = −2.944
```

| 真实错误率 | 每步漂移 `E[ΔΛ]` | 到边界所需决策数 |
|---|---|---|
| 0.20（坏） | +0.0444 | **≈ 66** |
| 0.15（灰） | +0.0037 | ≈ 800（长期悬而未决 ⇒ 视为可接受，转人工） |
| 0.10（好） | −0.0367 | ≈ 80（判为安全） |

`[推导]` 66 个坏决策即可回滚，同时把误回滚率压在 5%。

#### 6.3.3 硬开关（不经过统计）

| ID | 条件 | 动作 |
|---|---|---|
| **K1** | 单次决策造成净损失 ≥ 2 点魔力（`E3`） | 立即回滚 + 该局面入回归集 |
| **K2** | 换入者触发**诈死**（`κ = 2`）而阵亡 | 立即回滚（成本翻倍的错误不可容忍） |
| **K3** | 建矩阵耗时 > 2 s 连续 3 回合 | 降级为规则版（fail-safe），记录 |
| **K4** | `margin` 计算与执行结果矛盾 > 3 次（`\|Δ_t\| > 1.0`） | 暂停，人工复核 `M` 实现 |
| **K5** | 对局级胜率相对基线下降 > 5 pp（200 局窗口，单侧 95%） | 回滚 |

**K5 的统计口径** `[推导]`：200 局、基线 50%，检测 5 pp 下降的单侧检验功效仅 ~0.35 ⇒ **K5 只能作为"事后确认"，不能作为实时保护**。实时保护交给 K1–K4 与 SPRT。

### 6.4 与真实排位的隔离

| 手段 | 隔离强度 | 代价 |
|---|---|---|
| 影子期不执行 | 100% | 无因果信号 |
| 子账号 / 非排位场 | 100% | 样本代表性下降（对手强度分布不同） |
| S1 门限（高 margin + 高缓冲） | 中（错误不致命，但仍有影响） | 样本集中在"容易的局面"，结论外推受限 |
| 随机化对照 | 无（有直接影响） | 必须接受 50% 的次优执行 |

**推荐路径**：`子账号跑 S0/S1 → 排位跑 S2（随机化）→ 全量 S3`。若只有主账号，则 S1 的"高缓冲"门限必须严格执行，且每周复盘一次 `Mag^M ≥ 3` 子集的净胜率。`[经验]`

### 6.5 灰度期的日志闭环

每次决策必须落盘 `(policy_version, weights_version, matrix_hash, margin, g(z), a, b_t, Δ_t, ℓ_t, Λ_t)`。

回滚后：**冻结该 `matrix_hash`**，把失败样本回灌到 §5 的层 1 数据集，**先在离线重算 `Δ_t`**，确认问题出在矩阵定义还是权重，再修。禁止"回滚 → 直接改参数 → 再上线"（无归因的迭代在 15 s 回合制里是纯赌博）。
