## 失败的部分

### 1. BAND 名字带 OCR 全部 conf=0.00

`BAND -> 圆瞳毛虫 槽1 未识别 (conf 0.00)` × 4。**根因**：名字带 ROI
是在离线合成帧上标定的（胶囊下缘 +44px、左右 ±70px），但实机
`bar_partial_204511.png` 的布局是 1040×530（部分帧）——ROI 偏了。
需要用实机截图重新标定（bar_calib 脚本）。

### 2. CAST 我方播报没触发

`CAST -> 我方` 只有三条旧测试记录。这场我方出招很快（T1→T2 间隔
约 3 秒），播报条可能没被抓到。`_cast_banner` 的窗口需要放宽或
改用 `hud.read_cast_text` 的非阻塞轮询。

### 3. my_team 过期 → my_card_costs 空

岚鸟不在 my_team → `my_card_costs` 返回空 → 能量项失去区分度。
**这是设计预期**（表过期时的行为），但需要用户跑 `team_db.py --set`
更新配置，或用 session_moves 的三层链自动补。
