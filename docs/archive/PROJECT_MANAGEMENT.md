## 0. 铁律（改代码前先看这一段）

| 规则 | 原因 |
|---|---|
| **不要加任何守护进程 / watchdog / 开机自启** | 历史包袱：`espwatch.py`+`espd.py`(8765) 和 `espfast.py`(9998) 同时持有 BLE，互相抢板子，表现就是"板子开着却永远连不上"。现在只有 robot.py 自己持有 BLE |
| **一个进程一个职责** | 曾经一晚上堆了 46 个 `monitor.py`，吃掉 5.3 GB |
| **读不到就写 None** | 绝不填默认值，否则统计全错 |
| **改完必须真跑验证** | v2 换人、首领化、cardread 都是没验证就上线，白扔好几个回合 |
| **坐标系只有一套换算入口** | 见 `docs/ESP_AND_COORDS.md`，混用 = 点错位置 |

### 任务 3 · 分辨率自适应

**根因（已定位）**
固定坐标常量里混着 13px 边框 + 58px 标题栏。只按窗口大小整体缩放会把标题栏也缩掉，HUD 整体偏移几十像素，20px 高的血条直接读不到。

**已做**
- `Screen.sbox/grab_s`：窗口坐标（含边框）→ 客户区像素
- `Screen.sbox_client/grab_client`：客户区坐标 → 客户区像素
- `Screen.phys/phys_client`：两套坐标 → 屏幕物理坐标
- 所有抓图统一还原到**基准尺寸**（2560×1600），模板/阈值不用改
- `screen_state.py` 用**比例**（0~1）而不是像素

**待办**

126 个决策点即可无偏验证
