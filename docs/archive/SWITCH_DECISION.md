## 一、结论一句话

> 换人不是"血量低了就换"，而是**在收益矩阵里多一行**；
> 这一行的收益恒为负（`void_F ≡ 0`），只有当**放弃的输出 < 省下的承伤 + 换来的属性优势**时才成立。

## 二、核心公式（三份文档的交集）

### 收益矩阵一格

```
M[a][b] = w_H·ΔH + w_M·ΔMag + w_E·ΔE + w_T·ΔT + λ·ΔV
其中  void = 1[我先手] · 1[我的伤害 ≥ 对方当前血]   （乘性删除：对方这一手作废）
```

**`void` 是最容易被漏掉、也最致命的一项** —— v2 之前判错换人，就是因为它没算这个：
我们更快、能先手打死对面 → 对面那手根本不发生 → "挨 205" 是幻觉。

### 属性对位（B 文档 §3）

```
进攻面  O(i,j) = max_{s∈我方技能} Q(Π m(s, T_j))
防守面  D(i,j) = max_{t∈对面属性∪已观测技能} Q(Π m(t, T_i))
净值    net = α·log₂O − β·log₂D        （单位 bit）
```

**为什么用 log**：`log₂(n/r) = Δh + G − net` —— 属性、血量、面板在同一尺度上可加，**1 bit ≡ 血量比翻倍**。

**档位**：解包 `type_eff` 全表只有 0.5/1/2，**没有 0.75** → 0.75 不是乘积产物，必须直读。
**不用宝可梦的 ×3/×0.25**：多算 1 bit 就让判定翻倍，会系统性高估换人。

**互克只有 3 组**（冰↔地、萌↔恶、幽↔光）+ 自克（幽、龙）→ 必须单独处理（慢速方否决、+0.5 bit 补偿、无迟滞）。

### 求值（C 文档 §4）

```
value = max_i[ (1−ε)·行均值 + ε·行最小 ]        O(nm)
ε = 0 纯期望（对手随机），ε = 1 纯最坏（对手最优）
10×10 矩阵：d=1 → 0.5ms，d=2 → 0.1s，d=3 → 超预算
```

**ε 是唯一的"胆量旋钮"**，比调一堆阈值干净。

## 三、可执行判据（B 文档推导 + C 文档定理）

```
该换 ⇔ 换人后的期望局面 − 不换的期望局面 > 门槛
门槛 = 放弃的输出 − 省下的承伤 − 属性优势折算
```

具体三条快速否决（先做这三条，覆盖大部分情况）：

| 条件 | 结论 | 依据 |
|---|---|---|
| 我先手且能一击必杀 | **不换** | `void` 项：对面这手作废 |
| 对面一击 ≥ 我当前血 且 换上去那只扛得住 | **换** | 不换必死 |
| 我最大伤害 / 对面血量 < 15% 且 后排能打 ≥25% | **换** | 打不动 = 白送 |

## 四、落地顺序（按风险从低到高）

```
第 1 步  ✅ 已完成：影子日志（foe_damage 区间 + 打不动判据）
第 2 步  加 void 项：先手+致死 → 不换。这一条能修掉 v2 大部分误判
第 3 步  加属性净值 net（log2 bit），接进换人评分
第 4 步  加 ε-污染求值（先 ε=0.5），仍只写日志
第 5 步  用 SPRT 灰度：连续坏决策 66 次触发回滚
```

**第 2、3 步现在就能写**，不依赖模拟器，也不需要新识别能力（属性、血量、速度、卡面伤害都有）。

## 五、验证方案（C 文档 §5，很实用）

```
因为"同时出招 ⇒ 对面这一手和我们的选择独立"
⇒ 用实际发生的对面动作做一步评估是无偏的
⇒ 126 个决策点即可验证判据；检测崩盘率 20%→30% 需 348 局/臂
```

**"连续 3 次错误就回滚"是错的规则**（误报率 26%），用 SPRT(0.1, 0.2)。
