## 1. 问题形式化

### 1.1 为什么不能写成单步优化

单步贪心把"这一回合的伤害差"当成收益，会系统性错估换人，原因有三条可量化的：

1. **节奏是复利**：一击必杀 = 抹除对面一整手（【推导】，笔记已确认）。设抹除率为 `p_k`，则每回合我方实际获得 `1 + p_k` 个行动当量，单步模型只记 `1`。
2. **状态会留场**：印记、天气、觉醒、等级衰减都是跨回合状态（A4），换人不清除负面、也不保留正面增伤（除入场类）。收益是**状态差分**，不是伤害差分。
3. **不可逆**：一次性精灵（冥古龙每回合 −10 级且换下不重置）与"入场首击×2"的重置，都是**路径相关**的，单步收益函数写不下。

结论：必须写成**带吸收态的多阶段博弈**，单步判据只能作为它的**一阶近似**（§2.7 会证明三个直觉判据恰好是该近似在整数格上的三个特例）。

### 1.2 形式化：有限期双人零和同步行动不完全信息随机博弈

定义

```
G = ( N, X, {A(x)}, {B(x)}, T, r, γ, Θ, β₀, T_max )
N = {我, 敌}
```

- **类型**：`θ = (K_b, I_b, φ_b) ∈ Θ`，`K_b` 四技能集，`I_b` 三项满个体，`φ_b` 性格。`θ ~ β₀`（A7）。
- **公共状态** `x_pub = (a, h_a, e_a, b, M, M', t, ι)`，`ι` 为场效应（印记/天气/觉醒层数）。
- **私有状态**：我方 `K_a`（对面不知道）、对面 `θ`（我们不知道）。
- **信息集**：`I_t = (x_pub,0..t, 我方私有, 观测历史)`，即"公共史 + 我方私有"。
- **动作**：

```
A(x) = { 用技能 i : i ∈ K_a, e_a ≥ cost_i }  ∪  { 换入 j : j ∈ B_a }  ∪  { 聚能 }
|A(x)| ≤ 4 + 5 + 1 = 10
B(x) = 同构，|B(x)| ≤ 10（对面 4 技能 + 5 换人 + 聚能）
```

- **联合动作** `(u,v) ∈ A(x) × B(x)`，`|A×B| ≤ 100`。
- **转移**：`T(x' | x, u, v, θ)` 由 §1.3 的五阶段确定性算子给出，**仅在速度同值抽签处有随机性**（A5）。
- **收益**：吸收态给 ±1，中途 0（等价于"最大化到达 `M' ≤ 0` 的概率"，见 1.5）。

### 1.3 转移算子（五阶段，顺序即结算顺序）

```
阶段 1  应对判定：若 u,v 的技能类别满足"应对"关系 → 该方获得强制先手标记
阶段 2  先手判定：prio(u) vs prio(v) → 速度面板 → 抽签（A5）
阶段 3  结算先手方：伤害 / 状态 / 换人 / 聚能
阶段 4  存活检查：若阶段 3 造成 KO，则后手方阶段 4 **整段跳过**（关键非线性）
阶段 5  阵亡结算：M ← M − κ(阵亡者特性) − κ'(击杀者特性)，夹到 0；若 ≤0 → 吸收态
```

阶段 4 是全模型唯一的强非线性，也是"节奏"的来源：

```
若 d(u→v) ≥ h·H  则  v 的阶段 3 不发生  ⇒  (u,v) 的收益 = 只结算 u
```

### 1.4 目标函数

```
V(x,β) = max_{π} min_{σ}  E_{θ~β, 抽签} [ Σ_{t=0}^{T_max} γ^t r_t ]
r_t = +1  若 M' 首次 ≤ 0（在 t）
r_t = −1  若 M  首次 ≤ 0
r_t =  0  否则
```

三种等价写法，按需选用：

| 写法 | 表达式 | 用途 |
|---|---|---|
| 胜率 | `P(M' ≤ 0 before M ≤ 0)` | 直觉、报表 |
| 折扣收益 | 上式 `V`，`γ→1⁻` | 保证有限期收敛、可做 Bellman |
| 势差 | `V ≈ f(M' − M, 节奏 τ, 血量)` | 快速评估、冷启动 |

`M` 只有 0–4 共 5 个取值，`κ ≥ 1` ⇒ **对局长度上界** `T_max ≤ 8` 次阵亡链（双方各 4 点，最慢每次 −1），加上纯操作回合，实用 `T_max ≤ 20`。**有限期 + 吸收态 ⇒ 值迭代必收敛，无需无穷折扣。**

### 1.5 关键结构性结论：价值函数是 `θ` 上的有限加权和

由 A5（唯一随机性是抽签）与 A7（`θ` 固定）：

```
V(x,β) = Σ_{θ∈Θ} β(θ) · V_θ(x)          # V_θ 是纯确定性博弈的值
```

**推论**：贝叶斯评估不需要蒙特卡洛，只需枚举 `Θ` 的支撑。复杂度 `O(|Θ|)` 而非 `O(N_samples)`，且**零方差**。这是本问题比一般 POMDP 好算的根本原因，也是 §4 全部方案可行的前提。【推导】

### 1.6 精确解：Harsanyi 展开 + 序列式 LP

把 `θ` 交给"自然"在 `t=0` 抽取（A7），不完全信息博弈展开为**带不完全信息的扩展式博弈**。双人零和、完美回忆 ⇒ 精确解 = 序列式（sequence-form）LP：

```
max_{x}  min_{y}  xᵀ A y
s.t.  E x = e,  x ≥ 0        (我方实现计划，E 为序列约束矩阵)
      F y = f,  y ≥ 0        (敌方实现计划)
```

- `A` 的规模 = 叶子数 = `(|A||B|)^{T_max}`，**指数爆炸**。
- 但序列式 LP 的约束数 ∝ 信息集数，**关于树深是线性的**，关于 `|Θ|` 是线性的。
- 实用结论：**深度 ≤ 3 可精确求解**；更深必须近似（§5）。

【推导】+ 文献结论（Koller–Megiddo–von Stengel 序列式 LP）。

### 1.7 两个化简

| 化简 | 条件 | 结果 | 复杂度 |
|---|---|---|---|
| **R1 → POMDP** | 对手策略 `σ` 固定（脚本队 / 已学到的 policy） | 单人信念 MDP，Bellman：`V(x,β)=max_u Σ_θ β(θ) min? no → Σ β(θ) V_θ(x,u,σ)` | `O(|A||Θ|)` / 层 |
| **R2 → 信念 MDP + 对手模型** | 对手近似最优但对私有信息取期望 | `V(x,β)=max_u min_{σ} Σ_θ β(θ) E[V]`，用 `β` 而非 `θ` 做状态 | `O(|A||B||Θ|)` / 层 |
| **R3 → 完全信息近似** | 用 `β` 的**点估计** `θ̂`（MAP）替代 | 退化为确定性零和博弈，可做深搜 | `O((|A||B|)^D)` |

**工程推荐**：在线用 R3（快），离线/复盘用 R2（准），冷启动用 §7 的规则。

## 2. 判据推导

### 2.1 状态压缩：把血量换成"竞速数"

因为伤害是**确定整数**（A5），`V` 对 `h` 是**分段常数**，分段点恰是"还能挨几下"。定义两个整数：

```
n(a→b) = ⌈ h_b · H_b / d_max(a→b) ⌉      # 我要几手打死他
r(b→a) = ⌈ h_a · H_a / D̄(b→a) ⌉          # 他几手打死我   (D̄ = max over 其技能与 θ)
```

- `n = 1` ⟺ 一击必杀。
- `r = 1` ⟺ 会被一击必杀。
- `n > r` ⟺ **竞速输**（我先动手也打不完，他先打完）。

于是状态可粗粒化为 `(n, r, e_a, κ, κ', τ)`，`n,r ∈ {1..8}` ⇒ **状态空间 ≤ 8×8×11×4×4×5 ≈ 5.6×10⁴**，全部可枚举预计算成查表。这是全文档最重要的降维：所有"阈值"从此都是整数比较，**没有拍脑袋的 0.3/0.5**。【推导】

> 代价：忽略"多段伤害/回复/吸血/护盾"造成的中间态。修法是把 `r` 改成"剩余可挨次数"并允许半格（§5.3 的 HP 分桶）。

### 2.2 单调性引理（所有判据的地基）

**引理 1（单调性）** `V` 对以下变化单调不降：`M' ↓`、`M ↑`、`h_a ↑`、`h_b ↓`、`|B(x)| ↓`（对面可选动作变少）、`e_a ↑`、`τ ↑`。

**证明要点**：吸收态收益对 `M'` 递减、对 `M` 递增；其余变量只影响到达吸收态的路径集合，可在策略层面构造耦合（把新策略在旧策略的动作上"跟随"）。【推导】

**引理 2（抹除）** 若 `u` 使 `b` 本回合 KO，则对任意 `v`，`T(x,u,v,θ)` 与 `v` 无关；且 `V(x,u,·) ≥ V(x, switch, v)`，当 `d_max ≥ h_b H_b` 且 `u` 必先手。

**证明**：抹除后对面动作集 `B(x)` 塌缩为 `∅`，由引理 1（`|B| ↓` ⇒ `V ↑`）得攻击不劣；换人则 `M` 不变、`h_b` 不减、且白送对面一手（`|B|` 不塌缩），严格劣。**故 `n = 1 ⇒ 不换`，无需比较数值。**【推导】

> 边界：若对面存在"被击杀时反伤/同归"类效果（未确认），引理 2 失效，退化为 §2.6 的净收益比较。标【待验证】。

### 2.3 判据 K：一击必杀 → 不换（`n = 1`）

```
条件（点估计）：  d_max(a→b) ≥ h_b · H_b              ⟺ n = 1
条件（鲁棒）：    d_min(a→b) ≥ h_b^max · H_b^max      # 对 θ 取最坏
动作：            出手（不换）
```

鲁棒版本的 `d_min` 用 §7.1 的区间算术：对面体力取"三项满个体里含体力且性格 +血"的最大值，防御取最大值 ⇒ 得到**保证必杀**的下界。**只有保证必杀才允许跳过搜索直接出手**；点估计必杀仅作为搜索的排序先验。【推导】

**为什么这条优先级最高**：它把 `(n, r)` 里的 `n` 直接置 0（对面这只消失），同时 `M' −= κ'`，且**免去对面一手**。三重收益且无成本，任何其他动作都不可能更优（引理 2）。

### 2.4 判据 S：会被秒（`r = 1`）

```
条件：  D̄(b→a) ≥ h_a · H_a          ⟺ r = 1
```

此时"留场"的期望价值上界（假设对面一定打你）：

```
V_stay ≤ (1 − 1) · V_after + 1 · V_dead = V_dead
V_dead = V(M − κ, b 存活, 需换入)        # 我方 −κ 点魔力
```

**换人是否有效？** 只有存在 `j ∈ B_a` 满足

```
h_j · H_j  >  D̄(b→j)                    # 换入者能挨住这一手（A1 下）
```

才有 `V_switch(j) > V_dead`。若**所有** `j` 都挨不住，则换人只是"换一只去死"，`V_switch ≤ V_dead`，此时正确动作是**留下赌非攻击手**（防御/愿力/最大伤害），见 §8 的 `NO_ESCAPE` 分支。

**存在性判据（解析）**：

```
∃j:  H_j·h_j > D̄(b→j)  ⟺  max_j [ H_j h_j − D̄(b→j) ] > 0
```

若成立，选 `j* = argmax_j [ (H_j h_j − D̄(b→j)) / H_j ]`（**剩余可挨手数最大**），而不是"血量最高"。【推导】

### 2.5 判据 D：打不动（阈值 `θ*` 的解析式）

不做换人时，未来 `m` 回合内我能打出的总伤害 `≈ m · d_max`，能活 `m = r` 回合（忽略回复）。于是

```
能打死他  ⟺  r · d_max ≥ h_b · H_b  ⟺  d_max / (h_b H_b) ≥ 1/r  ⟺  n ≤ r
```

**所以"打不动"的阈值不是常数，而是 `θ* = 1/r`：**

```
θ*(r) = 1/r ,      r = 当前可挨手数
判据 D：  d_max(a→b) / (h_b · H_b)  <  1/r    ⟺   n > r    ⟹  换人候选
```

数值感（满血 `r = 4`）：阈值 `0.25`——每回合打不掉对面 1/4 血就是输的竞速。
残血 `r = 1`：阈值 `1.0`——**不能一击必杀就等于输**，这正好复现笔记里"残血必须必杀"的经验规则，但它是推出来的，不是拍的。【推导】

> 严格版含回复/吸血：`d_net = d_max − σ_b`（`σ_b` 为对面每回合净回复），判据变为 `d_net/(h_b H_b) < 1/r`；`d_net ≤ 0 ⇒ n = ∞ ⇒ 必换`。

### 2.6 判据 B：换人净收益

```
B(j) = E_β[ V(x ⊕ j, β') ] − max_{i∈K_a} E_β[ V(x, i, β) ] − C(j)
换人 ⟺ max_j B(j) > 0
```

其中 `x ⊕ j` 表示"`a` 下场、`j` 上场、其余不变"。成本项分解（每项都给形式，不给魔数）：

```
C(j) = c_tempo + c_entry + c_info + c_state − c_reset

c_tempo  = λ · d_max(a→b)              # 本回合零输出，按影子价格计
c_entry  = P(对面本回合为攻击手) · max(0, D̄(b→j) − h_j H_j) / H_j   # 换入者挨打（A1）
c_info   = λ_info · I(a 的技能池未被观测)   # 暴露信息，仅在对手会利用时有值
c_state  = Δ(负面印记/天气对我方的不利)     # 换人不消除（A4），故通常 ≈ 0，不是负成本
c_reset  = (m − 1) · d_first(j)             # 入场首击 ×m 的精灵：重置收益
```

- `λ`（伤害的影子价格）由**有限差分**标定：`λ = [V(x + 1 点伤害) − V(x)] / 1`，在模拟器里对 `(n,r)` 网格预计算成表。
- **`c_tempo` 的闭式**：在纯竞速模型（双方每回合各 1 杀）中，白送一手 ⟺ 对方多得 1 点魔力进度。因 `M = 4`，故

```
λ · d_max ≈ 1 个"竞速回合" ≈ κ 点魔力的 1/4 价值  ⇒  c_tempo ≈ 1/⌈M/κ⌉ 个胜率单位
```

即**换人的价格约为"1/4 条命"**。这解释了为什么换人只在"换完能翻盘竞速"时才划算。【推导，在竞速模型下】

- **A2 备选**（换人后结算、对面打在原场上）：`c_entry` 换成 `P(a 被 KO)·κ_a`，成本更高 ⇒ 更少换人。默认用 A1。

把 `V` 用一阶展开（`V ≈ V_0 + λ·(伤害差) + μ·(节奏差) + ν·(魔力差)`）代入，得到**可执行的整数判据**：

```
B(j) > 0  ⟺  [ r(j) − 1 − n(j) ]  >  [ r(a) − n(a) ]  +  c_info/μ
```

记 `Φ(x→j) = r(j) − n(j)` 为**竞速盈余**（`−1` 是挨的那一手）。于是：

```
换人 ⟺ ∃j:  Φ(j) − Φ(a) ≥ 1 + c_info/μ
```

这解释了经验规则"要换就换能**翻正**竞速的那只，换个'稍微好一点'的没用"——阈值是 `1`（一手），不是 0。**【推导】+【经验】一致**

> 本节所有 `d_max`、`D̄` 都已含**克制倍率**。属性对位不是额外加项，它的严格位置在 `n`、`r` 的构成里：`log₂(n/r) = Δh + G − net`（推导见 §3.4）。只读 §2 时，可以把它当作"`net` 已内含"的版本使用。

### 2.7 汇总表：三个直觉判据都是 `(n,r)` 的特例

| 判据 | 条件（整数形式） | 条件（比例形式） | 动作 | 依据 |
|---|---|---|---|---|
| **K 必杀** | `n = 1` | `d_max ≥ h_b H_b` | 出手，禁止换人 | 推导（引理 2） |
| **S 被秒** | `r = 1` | `D̄ ≥ h_a H_a` | 换人（若 `∃j` 能挨住）否则赌 | 推导 |
| **D 打不动** | `n > r` | `d_max/(h_b H_b) < 1/r` | 换人候选 | 推导 |
| **B 净收益** | `Φ(j) − Φ(a) ≥ 1` | 同上 | 换人 | 推导（一阶近似） |
| **E 无能量** | `e_a < min_i cost_i` 且对面有攻击手 | — | 换人（不聚能） | 推导 + 笔记 |
| **M 互克** | `O>1 ∧ D>1 ∧ v_j < v_b` | — | 否决该换入 | §3.7 |

最后一条单独说明：聚能是**状态技**，会被攻击打断（笔记已确认），且对面若带愿力还吃 ×2。所以

```
Payoff(聚能) = P(未被打断)·(5 能量) − P(被打断)·(伤害 + 1 回合节奏)
Payoff(换人)  = Φ 改进 − 1 回合成本
```

在"对面有攻击手"时 `P(打断) → 1`，聚能期望为负 ⇒ **换人严格优于聚能**（不是因为换人好，是因为聚能会归零）。【推导】

## 3. 属性对位的数学化

> 前两章把换人化成了 `(n, r)` 竞速，但 `d` 与 `D̄` 里藏着最大的一个乘区：**克制倍率**。
> 本章把"属性好不好打"变成一个可加减、可与血量互换的标量，并证明它**不是额外项**，而是竞速比值的对数分解里的一项。
> 全部倍率取自解包表 `type_eff`（324 条，`m ∈ {0.5, 1.0, 2.0}`，**全表无 0.75**，已核对）。【经验·已核对】

### 3.1 记号

| 符号 | 含义 | 取值 |
|---|---|---|
| `𝒯` | 属性全集 | 18 个：普通 火 水 草 电 冰 武 毒 地 翼 萌 幻 虫 幽 机械 龙 恶 光 |
| `T_i ⊆ 𝒯` | 我方第 `i` 只的**防守属性集**（1–2 个） | `|T_i| ∈ {1,2}` |
| `S_i` | 我方第 `i` 只**四张卡的技能属性**（多重集） | `|S_i| ≤ 4` |
| `m(s,t)` | 基础克制表，攻 `s` 打守 `t` | `{0.5, 1, 2}` |
| `Q(·)` | 组合档位映射（双属性相乘后钳制） | → `{0.5, 0.75, 1.0, 2.0}` |
| `T_j, S_j` | 对面在场精灵的防守属性集 / 技能属性集 | `T_j` 已知（身份可反查），`S_j` 未知 |
| `K_obs(j)` | 已**观测到**的对面技能属性集合 | 随对局增长 |
| `π_j(t)` | 对面技能属性的信念分布 | `Σ_t π_j(t) = 1` |
| `v_i` | 速度面板 | ℤ |

### 3.2 双向克制与"属性净值"

**进攻面**（我方能选技能 ⇒ 取 max，我是主动方）：

```
O(i,j) = max_{s ∈ S_i}  Q( Π_{t ∈ T_j} m(s,t) )
```

**防守面**（对面能选技能 ⇒ 也是取 max，但这是**他的**最优，即我的最坏）：

```
D(i,j) = max_{t ∈ T_j ∪ K_obs(j)}  Q( Π_{r ∈ T_i} m(t,r) )
```

**属性净值**（对数倍率，可加减）：

```
net(i,j) = α · log₂ O(i,j)  −  β · log₂ D(i,j)          α = β = 1 默认
```

`net` 的单位是 **bit**：

| `net` | 含义 | 直觉 |
|---|---|---|
| `+2` | 我打 2× 且挨 0.5× | 天胡对位 |
| `+1` | 单向优势（2× 或 0.5× 之一） | 值得为它换人 |
| `0` | 平对位 | 只看面板/血量/速度 |
| `−2` | 我打 0.5× 且挨 2× | 必须换走 |

**为什么用 log 而不是原始倍率**（三条，均可验证）：

1. **组合是乘性的**：双属性 `Q(Π)` 是乘法，`log` 把它变成加法 ⇒ `net` 可以直接和血量项、节奏项相加。
2. **同量纲**：血量、面板、伤害比在决策里全是"翻倍"级的变化（§3.4 证明竞速比值的对数恰好是这些项之和），`log₂` 让 1 bit 在四个维度上等价。
3. **抗主导**：原始倍率里一个 `2.0` 会吃掉加权和，`log` 下 `2×` 与 `0.5×` 等权反向（`+1` vs `−1`），符合"攻守对称"的博弈直觉。

> **不重复计数**：本系 `STAB = 1.25` **不进** `net`（它属于"技能与自身属性一致"的常数项，归入 §3.4 的 `d₀`）；减伤 `(1−r)` 与觉醒倍率同理另行处理。`net` **只**含克制乘区。若把 STAB 塞进 `O`，会与伤害公式重复乘一次，量级错 0.32 bit。【推导】

### 3.3 双属性相乘与档位钳制

单属性查表后**逐项相乘**，再映射到配置档位：

```
p = Π_{t ∈ T_j} m(s,t) ∈ {0.25, 0.5, 1, 2, 4}
Mtype = Q(p) ∈ {0.5, 0.75, 1.0, 2.0}          # 用 Mtype 避免与魔力 M 撞名
```

因为基础表只有 `{0.5,1,2}`（实测 324 条），乘积只可能落在 `{0.25, 0.5, 1, 2, 4}`：

| 乘积 `p` | 档位 `Q(p)` | 说明 |
|---|---|---|
| 0.25（双抗） | **0.5** | 下限钳制 |
| 0.5 | 0.5 | 直接命中档位 |
| 1.0 | 1.0 | 直接命中档位 |
| 2.0 | 2.0 | 直接命中档位 |
| 4.0（双克） | **2.0** | 上限钳制 |

**`0.75` 档的来源必须直读配置，不能用公式猜**：乘积集合里没有 `0.75`，而配置档位里有 ⇒ 它只能是配置对某些双属性组合**直接指定**的值（或另一种组合规则），不是乘法的产物。所以：

```
实现约定：Q 一律查 battle_config 的 (技能属性, 防守属性集) 表；
         若表缺失，退化为 Q(p) = clamp(p, 0.5, 2.0)，并标记该样本为低置信。
```

标【待验证】：`0.75` 的确切触发条件；一旦用真实伤害回放（公式已零误差）即可反解，成本很低。

**为什么不能用宝可梦的 ×3 / ×0.25**（四条，前两条是硬事实）：

1. **档位上限就是 2.0**：配置只有四档，`4×` 不存在。用 `4×` 会把双克伤害高估一倍。
2. **本系是 1.25 不是 1.5**（实测）：整个倍率体系比宝可梦"压缩"，极端值本来就不该出现。
3. **量化误差会直接翻转换人决策**：把双抗当 `0.25` 而非 `0.5`，防守端多算 1 bit ⇒ `r` 翻倍 ⇒ 系统性高估换入收益（§3.4 的兑换率）。反之双克多算 1 bit ⇒ 高估进攻、追着换人送死。
4. **可证伪性**：伤害公式已零误差校验过三张卡，任何 `4×`/`0.25×` 会立刻打偏 2 倍，不是"差不多"的量级。

### 3.4 `net` 如何进入换人判据（推导）

把伤害写成"中性倍率 × 克制倍率"：

```
d(i→j)   = d₀(i,j) · O(i,j)            # d₀ 含威力/攻防比/STAB/减伤
D̄(j→i)   = D₀(j,i) · D(i,j)            # D₀ 同理，D 是"我被克制"的倍率
```

代入 §2.1 的竞速数并取对数：

```
n = h_j H_j / d ,  r = h_i H_i / D̄

log₂(n/r) = log₂( h_j H_j / h_i H_i ) − log₂( d₀ / D₀ ) − log₂ O + log₂ D
          =  Δh  +  G(i,j)  −  net(i,j)
```

```
Δh      = log₂(h_j / h_i)            血量项
G(i,j)  = log₂(H_j · D₀ / (H_i · d₀)) 体型/种族项
net     = log₂ O − log₂ D            属性项
```

**这就是"净收益 = 属性 + 血量 + 体型"的严格来源**：三项在 log 尺度上**可加**。定义尺度不变的竞速盈余

```
Φ_log ≡ log₂(r/n) = net − Δh − G        # 越大越好；Φ_log > 0 表示竞速赢
```

立刻得到兑换率与符号约定：

```
1 bit 净收益  ⇔  n/r 减半  ⇔  击杀速度翻倍，或抗打能力翻倍
属性：O 或 D 每翻倍一次，net ±1 bit
血量：h_i 每减半，Δh 加 1 bit（我们吃亏）；每翻倍，Δh 减 1 bit
```

于是"属性优但血量差"有了精确答案，不再是模糊权衡：

```
属性好 +1 bit，但我们的血量只有对面的 1/4（Δh = +2）
⇒ Φ_log = +1 − 2 − 0 = −1  < 0
⇒ 不换（换上去也只是更快地死）
```

反过来：血量只有 1/2（Δh = +1）而属性 +1 bit ⇒ `Φ_log = 0`，恰好打平，此时才轮到"面板 `G`"与"谁先手"来分胜负。**这就是"权衡"的精确位置：`Δh + G − net ≈ 0` 的那条等值线。**

把 `net` 塞回判据时，**要用哪个 Φ 是个真问题**，两个度量给出的排序会不一样：

```
Φ_lin(i,j) = r − n                 # 单位"手"，与节奏成本同量纲
Φ_log(i,j) = log₂ r − log₂ n       # 尺度不变，1 bit 两侧等价
           = −( Δh + G − net )     # 由上式直接得到
```

| 度量 | 优点 | 缺点 | 用途 |
|---|---|---|---|
| `Φ_lin = r − n` | 与"白送一手"同量纲，可直接 `−1` | **对厚度有偏**：1 bit 进攻值 `w·n/2` 手，1 bit 防守值 `r` 手；`n≪r` 时防守 bit 系统性更贵 | 阈值、迟滞、成本加减 |
| `Φ_log = log₂(r/n)` | 尺度不变：属性 `+1 bit` ≡ 血量优势 `×2`，严格等价可加减 | 不含"±1 手"这种绝对量 | 跨维度兑换、排序、剪枝 |

**冲突时怎么办**：先用 `Φ_log` 排候选（避免"厚血幻觉"），再用整数 `(n, r)` 复核一遍成本项；两者矛盾且差距小于 0.5 手时，交给 §5 的搜索裁决。`Φ_lin` 的偏差不是游戏事实，是**线性度量的伪影**——同一只精灵在 `(r=8,n=4)` 与 `(r=4,n=2)` 时 `Φ_lin` 相差 2 手，但两者都是"竞速赢 2 倍"，实战价值相同（后者还更快结束，对面少一次自由行动）。

代价项仍在 `Φ_lin` 上扣减，因为"一手"是加性的：

```
换人 ⟺ ΔΦ_log > 0  且  ΔΦ_lin > 1 + c_info/μ
```

`w` 的来历：击杀不只是把 `n` 减 1，还**抹掉对面一手**（引理 2）并推进魔力，所以一个击杀回合值 `1 + 1/q` 个普通回合；`q` 是"还需几次击杀才能赢"，越接近终局 `w` 越大（`q=4 → w=1.25`，`q=2 → w=1.5`，`q=1 → w=2`）。【推导】

**帕累托写法**（第三种，不依赖任何标量化）：比较点 `(n_j, r_j)`，若 `n_j ≤ n_a ∧ r_j ≥ r_a` 且至少一严格，则 `j` 支配 `a`，直接换；不可比时才用上面两种度量。把 6 只画在 `(n, r)` 平面上，只有**前沿**上的点值得换（`O(6)` 次比较，可作搜索预剪枝）。

### 3.5 技能属性未知：进攻面用期望、防守面用最坏

严格说，`O` 在"我方 `S_i` 已知 ∧ `T_j` 已知"时是**确定量**，不确定性只来自两处：

| 方向 | 不确定源 | 口径 | 理由 |
|---|---|---|---|
| **进攻面** `O` | 对面**可能换人** ⇒ 目标防守属性变成 `T_j'` 的分布 | **期望**：`Ō = Σ_{j'} π(j') · O(i,j')` | 换人是对手对我们出招的**响应**，不是同回合的对抗选择；且该分布可学（§6.2），错误代价对称（打谁都是打） |
| **防守面** `D` | 对面 4 技能的**属性**未知 | **最坏**：`D = max_{t ∈ T_j ∪ K_obs(j)}` | 技能集是**私有信息 + 对方主动选择**；被秒的代价是 `−κ` 点魔力且不可逆，属于"一次性、代价不对称"的错误 |

形式化：

```
Ō(i,j)  = Σ_{j' ∈ S_op} π(j') · O(i, j')                  # 期望，用于估值
D̄(i,j)  = max_{t ∈ T_j ∪ K_obs(j)} Q( Π_{r∈T_i} m(t,r) )  # 最坏，用于承诺
net̂(i,j) = α log₂ Ō − β log₂ D̄
```

两条**收紧规则**（证据变强就放宽）：

```
若 k = |K_obs(j)| 已覆盖全部 4 槽（对面四技能全见）
   ⇒ 用 S_j 的实测属性集替换 T_j ∪ K_obs(j)，D 从"最坏"变为"精确"
若 π_j 的 Dirichlet 后验集中（最大后验 > 0.6 且 n_eff > 30）
   ⇒ 防守面也改用期望，并保留 CVaR_0.1 作下界
```

**为什么这个不对称是对的**（决策论理由，非拍脑袋）：期望准则在**可重复、分布可信、损失对称**时最优；极大极小在**一次性、分布不可信、损失不对称**时最优。换人的收益（打谁）可重复，被秒（丢 `κ` 点魔力）不可逆 ⇒ 两侧用不同准则不是不一致，而是**损失函数不同**。【推导】

### 3.6 Worked example：我方 6 只 × 岚鸟（翼）

对手：**岚鸟**，`T_j = {翼}`（解包 4 个个体 3037/3285/3286/3287 均为单翼，`T_j` 稳定）。单属性防守 ⇒ 无需组合，`O = max_{s∈S_i} m(s,翼)`。

翼的攻防两列（实测，可直接抄）：

```
m(· → 翼) : 普通1 火1 水1 草0.5 电2 冰2 武0.5 毒1 地1 翼1 萌1 幻1 虫0.5 幽1 机械1 龙1 恶1 光1
m(翼 → ·) : 普通1 火1 水1 草2   电0.5 冰1 武2  毒1 地0.5 翼1 萌1 幻1 虫2  幽1 机械0.5 龙0.5 恶1 光1
```

假设中性对位时 `n₀ = r₀ = 4`（**仅用于换算展示**，真实值由 §3.4 的 `d₀` 给出），`w = 1.25`：

| 我方 | `T_i` | `O` | `D` | `net` (bit) | `n` | `r` | `Φ_log` | `ΔΦ_lin` | 一击线 `h*_b` | 我方被秒线 `h*_a` |
|---|---|---|---|---|---|---|---|---|---|---|
| 音速犬 | 火 | 1.0 | 1.0 | **0.00** | 4 | 4 | 0 | 0.0 | 0.25 | 0.25 |
| 卡瓦重 | 草 | 0.5 | 2.0 | **−2.00** | 8 | 2 | **−2** | **−7.0** | 0.125 | 0.50 |
| 冥古龙 | 幽/龙 | 1.0 | 0.5 | **+1.00** | 4 | 8 | **+1** | **+4.0** | 0.25 | 0.125 |
| 银月狼王 | 冰 | 2.0 | 1.0 | **+1.00** | 2 | 4 | **+1** | **+2.5** | **0.50** | 0.25 |
| 恶魔狼 | 恶 | 1.0 | 1.0 | **0.00** | 4 | 4 | 0 | 0.0 | 0.25 | 0.25 |
| 绒光优优 | 地/光 | 1.0 | 0.5 | **+1.00** | 4 | 8 | **+1** | **+4.0** | 0.25 | 0.125 |

计算示例（冥古龙）：`O = max(m(幽,翼), m(龙,翼)) = max(1,1) = 1`；
`D = Q(m(翼,幽) × m(翼,龙)) = Q(1.0 × 0.5) = 0.5`；
`net = 0 − (−1) = +1`。**【经验·由解包表计算】**

三条可读出来的结论：

1. **同样 `+1 bit`，线性度量会给出三种不同答案——这是伪影，不是信息**。冥古龙 / 绒光优优 / 银月狼王 的 `net` 都是 `+1`，`Φ_log` 也都是 `log₂2 = 1`（完全并列）；但 `Φ_lin` 给出 `+4 / +4 / +2.5`，差额全部来自"谁的 `r` 基数更大"。若照 `Φ_lin` 选，会选冥古龙；但冥古龙要 4 手才杀完，银月狼王只要 2 手——**对手少两次自由行动**。所以正确顺序是：`Φ_log` 判并列 → 用 `n` 做 tie-break → **银月狼王胜出**。
2. **悬崖比斜率重要**。银月狼王的 `net` 只有 `+1`，但它的**一击线是 0.50**：岚鸟掉到半血以下时 `n = 1`，判据 K 直接锁死"出手"，其余所有讨论作废。所以实战里"银月狼王 vs 岚鸟"的触发点不是"血量对比"，而是 `h_b ≤ 0.5` 这个阈值。
3. **卡瓦重（草）是负资产**：`net = −2`，`Φ_lin = −7`，`Φ_log = log₂(2/8) = −2`，且敌方一击线对它是 `0.50`（半血即被秒）。它同时踩中"打不动"（`n=8 > r=2`）与"会被秒"（`r=2` 且 `h*_a = 0.5`）两条。

**双属性的威力（同一只精灵的 4 个形态）**：

| 卡瓦重形态 | `T_i` | `O` | `D` | `net` | `n` | `r` | 备注 |
|---|---|---|---|---|---|---|---|
| 单草 | 草 | 0.5 | 2.0 | −2.00 | 8 | 2 | 基准，灾难 |
| 草/火 | 草,火 | 1.0 | 2.0 | −1.00 | 4 | 2 | 只补了进攻 |
| 草/地 | 草,地 | 1.0 | 1.0 | **0.00** | 4 | 4 | 地抗翼（0.5）抵消草弱翼（2.0） |
| 草/冰 | 草,冰 | 2.0 | 2.0 | 0.00 | 2 | 2 | **互克**（§3.7），见下 |

`草/地` 的 `Q(2.0 × 0.5) = 1.0` 是**双属性相乘 + 档位**的核心价值：它把 `−2` 直接拉回 `0`。
`草/冰` 的 `net` 也是 `0`，但它的 `0` 是"`+1` 与 `−1` 相消"的**假中性**——见 §3.7。

> **数据校正**：`roco.sqlite3` 里 `银月狼王`（id `990000001`，`provisional=1`）的属性记成了 `虫`，与队伍配置的 `冰` 不符；`卡瓦重`（id `3294`，草/火）六项种族全为 50，是占位数据。本文按用户给定的 `冰`、并按 `3294` 的属性组合计算，**面板仍需回填**。【待验证】

### 3.7 边界：互相克制（mutual）——`net = 0` 但方差极大

解包表全量扫描，`m(a,b) = m(b,a) = 2.0` 的**互克对只有 3 组**（外加 2 个自克属性）：

```
互克：{冰, 地} , {萌, 恶} , {幽, 光}
自克：m(幽,幽) = 2.0 , m(龙,龙) = 2.0
```

这五类对位有一个陷阱：**`net` 恰好为 0**（`+1 − 1 = 0`），标量化判据会把它当"中性"处理，但它和真中性（`O=D=1`）在博弈上完全不同：

```
设 O = D = λ > 1
n = n₀/λ ,  r = r₀/λ
Φ  = r − n = (r₀ − n₀)/λ
```

- `λ = 2` 时 `n`、`r` **同时减半** ⇒ 双方各 2 手结束战斗，`Φ` 被压缩到原来的一半，**先手方的优势被放大到决定性**。
- 若原本 `n₀ = r₀ = 4`（势均力敌），则 `n = r = 2`：先手方第 2 手先到，胜负几乎完全由速度面板（或应对）决定。
- 数值上：`|Φ|` 整体乘 `1/λ`。原本"4 手缓冲"的对位在 `λ=2` 下只剩"2 手缓冲"，同样大小的血量扰动更容易把结论翻过来。

**记法**：

```
MUTUAL(i,j) = 1{ O(i,j) > 1 ∧ D(i,j) > 1 }
```

**算法里必须做的三件事**（缺一就会在互克局里做出系统性错误决策）：

| 触发 | 处理 | 依据 |
|---|---|---|
| `MUTUAL ∧ v_i < v_j` | 该换入**否决**（`ΔΦ_log` 直接记 `−∞`）：对方先手，我们这一手被抹除 | 引理 2 的对偶 |
| `MUTUAL ∧ v_i > v_j` | `net` 上加 `+0.5` bit 补偿（先手优势的等价折价） | 【经验，待标定】 |
| `MUTUAL` 且速度同值 | 退回 §4 的鲁棒准则，且 `δ_hys = 0`（不留迟滞余量） | 抽签方差最大 |

同时，互克对位的**判据 S 要改写**：`r = 1` 不再是"会被秒"的充分条件，因为对面也可能被秒；此时正确的问题是"谁先手"，故

```
MUTUAL ⇒ 用 min(n, r) 而非 (r − n) 作为危险性指标：
         min(n,r) ≤ 2 表示"这局只剩 2 个回合的容错"，任何换人都要 +1 bit 以上才做
```

【推导】+【待验证】（`+0.5 bit` 的折价系数需用对局数据标定）

> 附带的实现提醒：`光 ↔ 幽` 最容易漏算——只要观测到对面一张与 `T_j` 不同系的技能卡（例如光系精灵掏出幽系技能），`K_obs` 就会把 `D` 从 `1.0` 抬到 `2.0`，`r` 直接减半。**这是单条播报 OCR 能带来的最大单次信息增益**（§4.4），所以对互克系对手，第一张播报的权重应当调高。

### 3.8 汇总：属性对位在四个判据中的位置

| 判据 | `net` 的进入方式 | 是否额外加项 |
|---|---|---|
| **K 必杀**（`n=1`） | 一击线 `h*_b = O·d₀/H_b` | 否，内含 |
| **S 被秒**（`r=1`） | 被秒线 `h*_a = D·D₀/H_a` | 否，内含 |
| **D 打不动**（`n>r`） | `n,r` 由 `d = d₀O`、`D̄ = D₀D` 算出 | 否，内含 |
| **B 净收益** | `Φ_log` 判序，`Φ_lin` 扣成本 | 否，内含 |
| **搜索排序** | `net` 作一阶先验（`O(1)` 计算，免展开） | 是，仅作剪枝 |
| **互克否决** | `MUTUAL` 布尔标记 | 是，`±0.5 bit` |
| **换入候选剪枝** | 帕累托支配（`n_j ≤ n_a ∧ r_j ≥ r_a`） | 否 |

一句话：**`net` 不是"再加一个权重项"，它就是竞速数对数分解里的那一项**——把它写成加法项只是因为 `log` 让乘法变成了加法；实现时直接用含克制的 `d` 与 `D̄` 算 `n, r` 即可，`net` 只在**解释、剪枝、互克标记**三处显式出现，避免重复计数。

### 4.1 `Θ` 的结构与规模

```
Θ = Θ_ind × Θ_skill
|Θ_ind|   = C(6,3) × |N| = 20 × 31 = 620     # 三项满个体 × 性格
|N|       = 31                                # 解包 natures 表实测
|Θ_skill| = C(P_b, 4)                        # P_b = 该物种可学池大小
```

> `natures` 表实测 **31 条**：5 条"只升不降"、2 条"全中性"、24 条"一升一降"。
> 因此 `|Θ_ind| = 20 × 31 = 620`（此前按 21/25 估的 420 是错的，以本表为准）。【经验·已核对】

| 情形 | `|N|` | `|Θ_ind|` | `P_b` | `|Θ_skill|` | `|Θ|` |
|---|---|---|---|---|---|
| 友好上界 | 31 | 620 | 12 | 495 | **3.1×10⁵** |
| 中性估计 | 31 | 620 | 20 | 4845 | 3.0×10⁶ |
| 剪枝后（已见 3 技能） | 1（已定） | 20 | — | `P_b−3` | **≈ 1.7×10²** |

**关键**：`|Θ|` 不是常数，而是随观测**指数衰减**（§4.4）。这决定了方案选择：早盘用鲁棒，中盘用贝叶斯，残局用精确。

### 4.2 三种准则

**(a) 极小极大（鲁棒）**

```
u* = argmax_u  min_{θ∈Θ}  min_{v∈B(x)}  J(x,u,v,θ)
```

- 保证：对**任意**真实 `θ` 都不劣于 `max_u min_θ`，即"最坏情况下的最优"。
- 代价：过度保守。若 `Θ` 里有一个"我们永远打不过"的 `θ`（如满个体克制配置），`min_θ` 会把该动作的价值压到最坏值，导致**所有动作同分**、退化为随机。
- 修法：**Credible-set 极小极大**——只在 `β(θ) ≥ ε` 的 `Θ_δ` 上取 min，`Θ_δ` 取后验质量 `1−δ` 的最小集。

**(b) 贝叶斯（期望）**

```
u* = argmax_u  Σ_{θ} β(θ) · min_v J(x,u,v,θ)
```

- 由 §1.5，期望是**精确有限和**，`O(|Θ|)`，零方差。
- 保证：对先验正确时的期望最优；先验错了会被"自信地坑"。
- 实用变体：**CVaR 约束** `max_u E[J] s.t. CVaR_α(J) ≥ −c`。

**(c) 鲁棒-贝叶斯（熵罚 / KL 球）**

```
u* = argmax_u  min_{q: D_KL(q‖β) ≤ ρ}  E_q[ J*(θ) ],     J*(θ) = min_v J(x,u,v,θ)
```

对 `λ > 0` 有闭式（凸对偶）：

```
min_{q} E_q[J*] + λ D_KL(q‖β)  =  −λ · ln Σ_θ β(θ) e^{−J*(θ)/λ}
q*(θ) ∝ β(θ) · e^{−J*(θ)/λ}                     # 指数倾斜：向坏情况加权
ρ(λ) = D_KL(q*‖β)                                 # 用一维求根把 ρ 映射到 λ
```

- `λ → ∞` 退化为贝叶斯；`λ → 0` 退化为极小极大（只留 argmin 的 `θ`）。**一个旋钮连续插值两个极端。**
- 推荐：`ρ = 0.05 ~ 0.15 nats`（约"允许把 5%–15% 的信念质量挪到坏情况"）。【经验】

### 4.3 方案对比

| 方案 | 准则 | 单决策复杂度 | 数据需求 | 保证 | 失效模式 | 适用 |
|---|---|---|---|---|---|---|
| 极小极大 | `max min_θ min_v` | `O(|A||B||Θ|)`，`|Θ|` 大时需剪枝 | 无（只要 `Θ`） | 最坏情况最优 | 全动作同分 → 随机化 | 冷启动、开局面 1–2 回合 |
| Credible 极小极大 | 同上，`Θ_δ` | `O(|A||B||Θ_δ|)`，`|Θ_δ| ≪ |Θ|` | 弱先验 | 高概率最坏最优 | `δ` 调小则退化 | 通用默认 |
| 贝叶斯 | `max E_β` | `O(|A||B||Θ|)`（精确和） | 需可信先验 | 期望最优 | 先验错 → 系统性错 | 中后期、有历史对局 |
| 鲁棒-贝叶斯 | `max min_{KL≤ρ}` | `O(|A||B||Θ|)` + 一次求根 | 先验 + `ρ` | 邻域内最坏最优 | `ρ` 难定 | 高 stakes 决策（是否送死） |
| MAP 点估计 | 确定性博弈 | `O((|A||B|)^D)` | 无 | 无 | 类型判错 | 深搜（§5） |

**选型规则**：`|Θ_δ|` 的经验阈值 —— 大于 `10³` 用极小极大（贝叶斯和太慢且先验不可信）；`10²–10³` 用鲁棒-贝叶斯；小于 `10²` 用贝叶斯 + 精确搜索。【经验】

### 4.4 观测即剪枝：伤害反演（最强的信息通道）

对面每次打我们，都会**泄露它的攻击面板**。由伤害公式单调性，可反演区间：

```
给定观测 d、我方防御 D、威力 P、STAB、克制 E、减伤 r
g = STAB · E · (1−r)
base_lo = (d − 0.5)/g ,  base_hi = (d + 0.5)/g
A_lo = (base_lo − 0.5)·D/(P·L) ,  A_hi = (base_hi + 0.5)·D/(P·L)

A_b ∈ [A_lo, A_hi]  ⇒  删去所有使 A_b ∉ 该区间的 (I_b, φ_b)
```

面板公式又给出 `A_b = round(round(种族_b·1.1 + 0.1·... )·φ + 50)`，`φ ∈ {0.9,1.0,1.2}` ⇒ 每个候选 `(I_b,φ_b)` 对应一个**离散**攻击值。**一次命中通常能把 `|Θ_ind|` 从 420 砍到 1–10。**【推导】

**技能集剪枝（集合推断）**：

```
Θ_skill(t+1) = { K ∈ Θ_skill(t) : 观测到的技能 ∈ K }
|Θ_skill| = C(P_b − k, 4 − k),  k = 已观测到的不同技能数
```

`k = 1` 时降 `4/P_b` 倍；`k = 3` 时降到 `P_b − 3`。**所以前 2–3 回合的观测价值极高**，也解释了为什么"逼对面交出技能"本身是一种收益（信息价值）。【推导】+【经验】

**信息价值（EVSI）** 可显式入账：

```
EVSI(u) = E_o[ max_{u'} E_{β(·|o)}[J] ] − max_{u'} E_{β}[J]
```

当 `EVSI > c_info` 时，主动"试探"（出低伤害技能看对面反应）是正收益的。【推导】

### 5.1 单回合贪心为什么不够（四个可量化的机制）

| 机制 | 贪心的错估 | 量级 |
|---|---|---|
| **节奏复利** | 只记 `1` 个行动，实际每次击杀记 `1 + p_k` | `τ` 每回合 `×(1+p_k)`，3 回合可差 1.5 倍 |

| **一次性精灵路径依赖** | 冥古龙每回合 −10 级，等待有成本 | 线性衰减，每回合可算 |

总评估次数    C_D = N_D · S
每节点开销    solve 10×10 矩阵：fictitious play 迭代 K 次 → O(K · 100)，取 K = 30 ⇒ ~3×10³

## 6. 在线学习

### 6.1 二元倾向：Beta-Bernoulli

事件示例：`s_t = 1{对面在被威胁时选择换人}`、`1{对面在残血时聚能}`、`1{对面用状态技}`。

```
先验      θ ~ Beta(α₀, β₀)          # α₀=β₀=1 ⇒ 均匀
更新      α ← α + s_t ,  β ← β + (1−s_t)
后验均值  θ̂ = α/(α+β)
后验方差  Var = αβ / [(α+β)²(α+β+1)]
可信区间  θ ∈ [θ̂ − z_{1−δ/2}√Var, θ̂ + ...]   # 正态近似，α+β ≥ 10 后可用
```

**用途**：`P(对面换人)` 直接进 §2.6 的 `V_switch` 期望（若对面会换，我们的"打"会落空，`V_stay` 下降 ⇒ 更倾向稳定输出）。

**数值例**：`Beta(1,1)` 观测 5 次里 3 次换人 ⇒ `Beta(4,3)`，`θ̂ = 0.571`，`sd = 0.175`，95% 区间 ≈ `[0.23, 0.91]`——**5 个样本还不足以支撑"他就爱换"的结论**，这正是需要 Thompson 的原因。

### 6.2 多元选择：Dirichlet-multinomial

事件：对面从 4 技能里选了哪个、换到哪只。

```
p ~ Dir(α₁..α_K),  Σα = α₀
更新  α_k ← α_k + 1{k 被使用}
预测  P(k) = α_k / α₀          # 后验预测
```

**分层先验（冷启动关键）**：`α_k = α₀ · w_k`，`w_k` 来自**同物种历史对局**的统计（empirical Bayes），使新对手的先验不是均匀而是"该物种常见配招"。

### 6.3 技能集推断（不是分布，是集合）

见 §4.4：`Θ_skill` 是**支持集收缩**，不是概率更新。与 5.2 互补：

```
已知技能集 K_obs ⊆ K_true，|K_obs| = k
剩余槽位先验  Dir(α) over P_b \ K_obs，取 top-1 填满 ⇒ |Θ_skill| = P_b − k（若 4 槽已满）
```

### 6.4 非平稳：指数遗忘

版本/环境中对手在变，用遗忘因子 `λ_f`：

```
α ← λ_f·α + 1 ,   β ← λ_f·β + (1−s)
有效样本量  n_eff = 1/(1−λ_f)      # λ_f=0.99 ⇒ 100 局记忆
```

`λ_f` 取 `0.98–0.995`；对"换人倾向"这类**稳定习惯**用大 `λ_f`，对"当前 meta 配招"用小 `λ_f`。【经验】

### 6.5 Thompson sampling（探索）

```
每回合采样  θ̃ ~ Beta(α,β)  或  p̃ ~ Dir(α)
用 θ̃ 替 β 跑 §2/§5 的决策
```

- 保证：贝叶斯后悔 `E[Regret_T] = O(√(K T ln K))`（有限臂 bandit，K 为有效动作数）。【推导/文献】
- 实践意义：**前期自动多试探**（后验宽 ⇒ 采样方差大 ⇒ 偶尔选"信息量大"的动作），后期自动收敛到贪心。这正好替代手写的 ε-greedy。

### 6.6 更新流水（对局内）

```
每回合结束：
  1. 解析播报 → 对面技能 k        → α_k += 1；K_obs ∪= {k}
  2. 解析伤害 d → 反演 A_b        → 剪 Θ_ind（§4.4）
  3. 观测换人/聚能/状态技         → Beta 更新（对应事件）
  4. 若对面阵亡 → 观测其特性扣点   → 更新 κ'（魔力计数直接可读，误差 0）
  5. 局面终了 → 把 (局面, 动作, 结果) 入日志，供 §7.3 影子评估
```

## 7. 冷启动

### 7.1 区间算术：悲观承诺，乐观规划

我方 6 只面板未录全、对面个体未知 ⇒ 所有量算成区间 `[·_lo, ·_hi]`。

**原则**：

```
承诺型决策（必杀、必挨、送死）→ 用悲观界（保证成立才做）
规划型决策（排序、剪枝、估值）→ 用点估计（均值，避免过度保守）
```

具体：

| 量 | 悲观（判据用） | 乐观（排序用） |
|---|---|---|
| `d_min(a→b)` | 对面体力最大（含体力满个体+血性格）、防御最大 | 均值 |
| `D̄(b→a)` | 对面攻击最大（含攻满+攻性格）、我方防御最小 | 均值 |
| `H_b` | 三项满个体里**含体力**的配置（`C(5,2)=10` 种） | `C(6,3)` 平均 |

只有 `d_min ≥ h_b^max H_b^max` 才允许"保证必杀"路径；否则一切走搜索。

### 7.2 退化策略：规则级联（无模型也能跑）

按 `(n,r)` 与能量排序，**每条规则都可回退到上一阶**：

```
R0  e_a < min cost 且 对面有攻击手        → 换人（禁聚能）      §2.7-E
R1  n = 1（保证必杀）                     → 出手               §2.3
R2  r = 1 且 ∃j 能挨住                    → 换 j*              §2.4
R3  r = 1 且 无 j 能挨住                  → 留场赌非攻击手      §2.4
R4  对面为引擎型 且 t ≤ 3                 → 打引擎手/不换      笔记【经验】
R5  n > r 连续 2 回合                      → 换 Φ 最大者        §2.5
R6  入场首击型且本回合可安全重置           → 换下再上           §2.6 c_reset
R7  否则                                  → 最大伤害技能
```

`R5` 的"连续 2 回合"是**迟滞（hysteresis）**：单回合 `n > r` 可能是对面刚换入克制手，一回合后可能反转。要求 `Φ` 改进 `≥ 1 + δ`（`δ = 0.5` 手）连续 `k = 2` 回合，避免来回换人抖动。【经验】

### 7.3 影子评估（shadow evaluation）

规则跑在线、模型跑离线，用**反事实**给规则打分，逐步决定"哪类局面可以交给搜索"。

离线数据集 `D = {(x_t, a_t, r_t)}`，行为策略 `μ`（= 规则），目标策略 `π`（= 搜索）。

```
IPS：   V̂_IPS(π) = (1/n) Σ_t  [π(a_t|x_t)/μ(a_t|x_t)] · R_t
DR：    V̂_DR(π)  = (1/n) Σ_t  { V̂(x_t) + [π(a_t|x_t)/μ(a_t|x_t)]·(R_t − V̂(x_t)) }
ESS：   n_eff = (Σ w)² / Σ w²          # 有效样本量，< 0.1n 则不可信
```

- `R_t` 用**终局胜负**（`±1`），因为中途收益为 0（§1.4）。
- `R_t` 需从 `t` 起折扣：`R_t = γ^{T−t}·(±1)`。
- 只有当 `n_eff > 200` 且 `V̂_DR(π) − V̂_DR(μ) > 0` 的**置信下界**为正，才把该类局面从规则切到搜索。【推导】+【经验】

### 7.4 上线门槛（安全闸）

```
允许换人 ⟺  B_lcb(j) > 0   且   B_lcb(j) > δ_hys   （δ_hys = 0.5 手）  且   连续 1 回合成立
B_lcb(j) = B̂(j) − z_{0.95} · σ_B(j)/√n_eff
```

冷启动期 `σ_B` 大 ⇒ `B_lcb` 保守 ⇒ 只在明显赚时才换。随数据积累自动放开。

### 7.5 退化路径表

| 数据完备度 | 可用判据 | 决策器 | 预期 |
|---|---|---|---|
| 仅身份 + 血量 | `n,r` 用种族值区间 | 规则级联 R0–R7 | 不亏，抓 80% 的明显换人点 |
| + 我方面板录全 | 精确 `r`、`d_i` | 规则 + D=2 搜索 | 抓必杀/被秒交换 |
| + 对面技能观测 1–2 个 | `Θ_skill` 收缩 | 贝叶斯 D=2 | 预判换人/聚能 |
| + 50 局日志 | Beta/Dirichlet 收敛 | 鲁棒-贝叶斯 D=2~3 | 接近最优 |

## 8. `should_switch(state)` 伪代码

```python
def should_switch(x, beta, Theta, cfg):
    """
    返回 (bool, target, reason)
    x: 公共状态 (a, h_a, e_a, b, h_b_interval, M, M', t, iota)
    beta: 对 θ 的信念（有限支撑）
    """
    # ---------- 0. 预处理：把连续量压成整数竞速数（§2.1） ----------
    d_max, i_best = max_damage(x, optimistic=True)     # 乐观用于排序
    d_min         = min_damage(x, Theta)               # 悲观用于承诺
    H_b_hi        = H_max(b, Theta)                    # 对面体力上界
    n   = ceil(x.h_b_hi * H_b_hi / d_max)              # 我几手打死他
    r   = ceil(x.h_a * H_a(x.a) / max_threat(b, x.a, Theta))
    Phi = r - n                                        # 竞速盈余
    q   = ceil(x.M_prime / x.kappa_prime)              # 还需几次击杀（§3.4）
    w   = 1 + 1 / max(q, 1)                            # 击杀回合的权重

    # 属性对位（§3）：O 取我方技能最优，D 取对面技能最坏（§3.5）
    O = lambda i, j: max(Q(prod(m, s, T(j))) for s in S(i))
    D = lambda i, j: max(Q(prod(m, t, T(i))) for t in T(j) | K_obs(j))
    net      = lambda i, j: log2(O(i, j)) - log2(D(i, j))
    MUTUAL   = lambda i, j: O(i, j) > 1 and D(i, j) > 1     # §3.7
    # 注意：d_max / max_threat 已含克制倍率，net 只用于解释、剪枝、互克否决，
    #       不得再乘一次（§3.8 的"不重复计数"）

    # ---------- 1. 判据 E：没能量且对面能打断 → 只能换 ----------
    # 依据：聚能是状态技、会被攻击打断；打断概率→1 时聚能期望为负（§2.7-E）
    if x.e_a < min_cost(x.a) and opponent_has_attack(b, Theta):
        j = best_entry(x, beta)                        # 用 Φ(j) 排序，非血量
        return True, j, "E: 无能量，禁聚能"

    # ---------- 2. 判据 K：保证一击必杀 → 绝不换 ----------
    # 依据：引理 2，抹除对面整手，三重收益零成本（§2.3）
    if d_min >= x.h_b_hi * H_b_hi:
        return False, None, "K: 保证必杀"

    # ---------- 3. 判据 S：会被秒 ----------
    # 依据：留场价值 ≤ V_dead；换人只有当换入者能挨住才有效（§2.4）
    if r == 1:
        survivors = [j for j in bench(x)
                     if h_j(x, j) * H_j(j) > max_threat(b, j, Theta)]
        if survivors:
            # 选"剩余可挨手数"最大者，不是血量最高者
            j = argmax(survivors,
                       key=lambda j: h_j(x,j) * H_j(j) / max_threat(b, j, Theta))
            return True, j, "S: 被秒，换入可存活"
        else:
            return False, i_best, "S: 无处可逃，留场赌非攻击手"

    # ---------- 4. 判据 D：竞速输（打不动） ----------
    # 依据：d_max/(h_b H_b) < 1/r ⟺ n > r（§2.5）
    if n > r:
        # 4a. 先算净收益，避免"换个稍微好一点"的无效换人
        best_j, best_gain = None, -inf
        for j in bench(x):
            # 互克否决（§3.7）：属性互克且我更慢 ⇒ 换上去就是被抹除
            if MUTUAL(j, b) and v(j) < v(b):
                continue
            n_j = ceil(x.h_b_hi * H_b_hi / d_max_j(j, b))   # d 已含 O
            r_j = ceil(h_j(x,j) * H_j(j) / max_threat(b, j, Theta))  # 已含 D
            # 换人成本：白送一手 ⇒ 对面进度 +1 ⇒ 换入者 -1 手（A1）
            if r_j <= 1:                    # 换上去就被秒，等价于送死
                continue
            Phi_j = (r_j - 1) - n_j
            # 尺度不变度量（§3.4）：先看 Φ_log，避免"厚血幻觉"选错人
            phi_log = log2(r_j - 1) - log2(n_j)
            if phi_log <= cfg.phi_log_min:      # 换完仍在竞速输/打平
                continue
            gain  = Phi_j - Phi
            # 互克补偿（§3.7）：先手方白赚一手；x bit 在 Φ_lin 上值 w·n·x·ln2 手
            if MUTUAL(j, b) and v(j) > v(b):
                gain += w * n_j * cfg.mutual_bit_bonus * LN2
            # 影子价格校验（§2.6）：gain 必须跨过 1 手 + 信息成本
            gain -= cfg.c_info / cfg.mu
            # 入场首击重置收益（§2.6 c_reset）
            gain += reset_bonus(j, x) / cfg.mu
            # 帕累托预剪枝（§3.4）：被支配的候选直接跳过
            if dominates(x.a, j, b):
                continue
            if gain > best_gain:
                best_j, best_gain = j, gain
        # 4b. 贝叶斯/鲁棒校验：AC 下界必须为正（§4.2、§7.4）
        B_lcb = best_gain - cfg.z * sigma_gain(beta) / sqrt(cfg.n_eff + 1)
        if B_lcb > cfg.delta_hys:                      # 迟滞，防抖动（§7.2）
            return True, best_j, f"D: 竞速翻正 gain={B_lcb:.2f}"
        return False, i_best, "D: 无换人可翻正"

    # ---------- 5. 搜索：深度 2 的极小极大 + 信念加权（§5.2） ----------
    # 复杂度 O(|A||B||Theta_delta|) ≈ 100 × 20，剪枝后 < 8e4
    V_stay   = max_{u in skills(x)}  min_{v} E_beta[ J(x,u,v,theta) ]
    V_switch = max_{j in bench(x)}   min_{v} E_beta[ J(x,j,v,theta) ] - C(j)
    if V_switch > V_stay + cfg.delta_hys:
        return True, argmax_j(V_switch), "SEARCH: 多回合视野翻正"

    return False, i_best, "默认最大伤害"
```

**分支—依据对照表**

| 分支 | 数学依据 | 依据类型 |
|---|---|---|
| `E` 无能量 | 聚能期望 < 0（打断概率→1，且愿力 ×2） | 推导 + 笔记 |
| `K` 必杀 | 引理 2（抹除 ⇒ 单调性） | 推导 |
| `S` 被秒 | `r=1 ⇒ V_stay ≤ V_dead`；存在性判据 | 推导 |
| `S` 无处可逃 | 所有 `j` 都挨不住 ⇒ 换人 = 换一只去死 | 推导 |
| `D` 竞速 | `θ* = 1/r`，`n > r` | 推导 |
| `D` 净收益 | `Φ(j) − Φ(a) ≥ 1`，`−1` 来自白送一手 | 推导（一阶） |
| `D` 互克否决 | `O>1 ∧ D>1 ∧ v_j < v_b ⇒ −∞` | 推导（§3.7） |
| `D` 帕累托 | `n_j ≤ n_a ∧ r_j ≥ r_a` 支配则剪 | 推导（§3.4） |
| `D` 竞速门槛 | `Φ_log = log₂(r_j−1) − log₂(n_j) ≤ 0` 则弃 | 推导（§3.4 尺度不变） |
| `D` 迟滞 | 防抖动，`δ = 0.5` 手 | 经验 |
| `SEARCH` | D=2 极小极大 + 贝叶斯 | 推导 |

## 附：一句话总结

> 换人的本质是**用一手节奏买一次竞速翻正**。
> 判据不是"血少就换"，而是 `n > r`（竞速输）且 `Φ(j) − Φ(a) ≥ 1`（翻正且付得起一手）。
> 而 `n`/`r` 的对数分解 `log₂(n/r) = Δh + G − net` 说明：**属性、血量、面板是同一枚硬币的三面**，
> 1 bit 属性 ≈ 2 倍血量 ≈ 击杀速度翻倍——所以"属性优但血少"从来不是权衡，是一次减法。
> 必杀（`n=1`）永远优先于换人，因为它是唯一"零成本三重收益"的动作；
> 被秒（`r=1`）时的正确问题不是"换不换"，而是"**有没有一只换上来能挨住**"。
> 唯一需要额外标记的是**互克**（冰↔地、萌↔恶、幽↔光、幽↔幽、龙↔龙）：`net = 0` 是假中性，真正决定胜负的是速度。
