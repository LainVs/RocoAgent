## 排除了两个方向（都是实测，不是猜）

### A. 放大倍数 —— 无效

扫 fx = 1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 3.5：

```
fx=1.0  命中 2
fx=1.5  命中 3
fx=2.0  命中 3
fx=2.5  命中 3   <- 当前值，已在最优区间
fx=3.0  命中 3
fx=3.5  命中 3   <- 开始抖动（1176 vs 117E）
```

### C. 三帧投票 —— 无效

`诉毁` 在同一场连读 3 次**完全一样**，是系统性误读而非随机抖动。
投票对系统性误读不起作用。

## 采用的方案与安全边界

判据：**等长 + 编辑距离 <= 1，且候选唯一**。

实测证据（20 组真实配置 + 4 组危险场景 + 5 组全库查询）：

```
配置层 20/20 正确反查，0 误配

必须拒绝的场景（全部正确拒绝）：
  raw='诋毁' 对 [诋毁,底毁,抵毁]       -> 拒（3 候选）
  raw='火云车' 对 [火云车,火云马,火云箭] -> 拒
  raw='诉毁' 对全库（焚毁/诋毁）         -> 拒
  raw='扬沙' 对全库（扬尘/扬沙/流沙）     -> 拒
  raw='鼎管奔流' 对全库                 -> 唯一「筛管奔流」，采纳
```

**核心性质：模糊时一律拒绝，只在唯一时采纳。** 宁可漏读，不可误配。

这与两级词表互补：词表越小唯一性越容易成立（4 词配置层效果最好），
退化到全库层时绝大多数会被拒。
