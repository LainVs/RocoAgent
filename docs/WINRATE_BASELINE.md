## 这是累计战绩，不是今日增量

数字单调递增（123→124 胜，149→152 负），说明是**账号累计战绩**。
今日增量需要前后差值：

```
07:37 -> 08:15（38 分钟）
  胜 +1，负 +3
```

样本太小（4 局），不能据此判断今日策略效果。

## 如何用这个数字

1. **作为长期基线**：45% 是当前策略的真实水平。
2. **判断改动效果**：需要看"改动后的增量胜率"，而不是累计胜率。
   至少积累 20~30 局再比较。
3. **注意干扰**：机器人在大厅卡死、多实例冲突期间的对局会拉低统计。
