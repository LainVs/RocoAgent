# 计划：修复对手行为模型的样本切碎问题

## 现状（2026-11-21 07:55 实测）

```
总样本 243，对位数 147
MIN_SAMPLES = 12

样本数分布：
  12+    1 组    <- 只有 1 组可用
  8-11   4 组
  4-7   26 组
  2-3   38 组
  1     78 组
```

`anticipate` 的判据是"样本 >= 12 才给建议"，所以**基本无法生效**。

## 两个数据问题

### 问题 1：我方名字带 `#编号`，把样本切碎

立绘识别输出的是模板文件名（`银月狼王#2`、`冥古龙#17`、`音速犬#5`），
同一只精灵有多个立绘变体就被当成不同精灵：

```
我方（立绘名）种数: 26
  音速犬        37 组
  wolf         25 组      <- 和「音速犬」是同一只！
  恶魔狼        18 组
  银月狼王#2     17 组      <- 和「银月狼王#7」是同一只
  冥古龙#17      8 组
  冥古龙#27      5 组
```

带 `#` 的对位有 **62 组、131 条样本（54%）**，全部被切碎。

**注意**：`wolf` 和 `音速犬` 是同一只精灵的两种命名
（`wolf` 是旧模板名，`音速犬` 是新模板名）。

### 问题 2：`60级水桶模型` 是训练假人，污染模型

```
含「水桶」的对位: 13 组，47 条样本（19%）
```

这是游戏里的训练假人（固定血量、固定行为），不是真实对手。
它的行为概率（`attack=1.00`）会污染统计，必须排除。

## 修复方案

### 1. 归一化我方名字（新增 `_norm_me`）

```python
def _norm_me(name):
    """把立绘模板名归一成种族名。"""
    if not name:
        return name
    # 去掉 #编号
    base = name.split("#")[0]
    # 旧模板名 -> 种族名（wolf 是音速犬的旧模板）
    return ALIASES.get(base, base)
```

`ALIASES` 从现有数据里维护，初始：
```python
ALIASES = {
    "wolf": "音速犬",
    "wolf_leader": "音速犬",   # 首领化形态，行为统计上视为同一只
}
```

### 2. 排除训练假人

```python
DUMMY_FOES = ("60级水桶模型",)
```

在 `build` 里跳过这些对位，不计入样本。

### 3. 降低 MIN_SAMPLES（数据驱动）

修完 1+2 之后重新统计分布，看 12 是否还合理。
如果合并后 8~11 条的组数明显增加，可以把门槛降到 8，
但**必须先验证这些样本的预测准确率**，不能凭感觉降。

## 验收标准

1. 归一化后对位组数下降、单组样本数上升
2. 达到门槛的组数从 1 增加到 >= 5
3. `p_buff` 不再异常偏高（当前 0.455，疑似复制技能误判）
4. 单测覆盖归一化和假人排除

## 不做的事

- 不凭空降低 MIN_SAMPLES（用户要求"宁可不用也不拿噪声决策"）
- 不动 `foe_types` 缺失问题（那是识别层的事，另开任务）
