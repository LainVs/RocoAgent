## 本轮修复：BAND 候选词限定本宠技能池

### 实测问题

全库 1269 个技能词表匹配时：
```
"岩脉崩毁" 读成 "岩脉崩段" -> 0.750  （被 0.90 门槛拒）
单个字 "月" -> 匹配到 "月蚀" 0.830   （容易误配）
```

### 修法

`read_band` 的候选词改为**这只精灵自己的可学技能池**（几十个）：
- 分母小 → 1 字偏差的分数更高（0.75 → 更接近 1.0）
- **不可能配到别的精灵的技能**（这是硬约束，比阈值可靠）
- 门槛：词表 <60 个时用 0.80，否则仍用 0.90
