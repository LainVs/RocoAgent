# 卡面伤害的真实语义（2026-11-21 破解）

> 用户的关键解释：
> "火云车是火系 150 伤害，算上本系加成是 175 伤害，
> 克制或者开局火狗伤害加倍是 350，火狗刚上伤害加倍加克制是 700"

---

## 一、结论

**卡面数字 = 威力 × STAB × 属性克制 × buff**

**不含 `atk/defn` 的除法**。它是"威力等效值"，不是最终伤害。

### 用用户的数字验证

```
火云车 power=140（用户记作 150，实际 140）
  140 × 1.25（本系 STAB）= 175    <- 用户说的"本系加成 175"
  175 × 2（属性克制）    = 350    <- 用户说的"克制 350"
  350 × 2（专注力 +100%） = 700    <- 用户说的"刚上场加倍 700"
```

三个数字全部对上。

### 实测数据佐证

按 `(我方, 槽位, 对手)` 分组，算 `读数 / (power × STAB)`：

```
音速犬 火云车(p=140, 本系 STAB=1.25) vs 60级水桶模板
    基数 175.0，读数分布：1.0x(13次)、2.0x(9次)
    -> 175 和 350，正是「本系」和「本系+克制」
    整齐倍数占比 79%

音速犬 火云车 vs 雪影冰灵
    基数 175.0，读数：2.0x(6次)、1.0x(4次)
    整齐倍数占比 81%

音速犬 闪光冲击(p=100, 非本系) vs 60级水桶模板
    基数 100.0，读数：1.0x(14)、4.0x(6)、2.0x(5)
    -> 100 / 400 / 200（4x = 双倍克制+加倍）
    整齐倍数占比 91%
```

**读数除以基数后是 0.25 / 0.5 / 1 / 2 / 4 这种整齐倍数**，
证明卡面确实是纯乘法，没有 atk/defn。

## 二、这解释了什么

### 为什么之前的校准误差 46%

我之前用"模拟器算的最终伤害"去比"卡面"，但两者算的是**不同的量**：

```
模拟器： 伤害 = (atk/defn) × power × 0.9 × STAB × 克制 × buff
卡面：   数字 = power × STAB × 克制 × buff
```

差的正是 `(atk/defn) × 0.9` 这一项。

以音速犬(atk=221) 打 冰钻布鲁斯(def=185) 的火云车为例：

```
卡面 = 140 × 1.25 × 2(火克冰) = 350
模拟 = (221/185) × 140 × 0.9 × 1.25 × 2 = 377
差   = 377 / 350 = 1.08  （这次巧合接近）
```

但换成别的 atk/defn 组合差异就大了。

### 为什么 67 这个值不是误读

用户质疑"卡面 67 肯定是读数错了吧"。

查原始 OCR：`t='67'`，确实读到 67，且 `c='red'`（被抵抗）。

反推：

```
67 / 175（火云车本系基数）= 0.383
```

0.383 不整齐，但如果对手有**防御 buff** 就会降。

**更可能的解释**：`67` 是「被双抵抗 × 有防 buff」的组合。
另一个可能是 OCR 把 `167` 读成了 `67`（少一位）——
`167/175 = 0.95`，接近 1.0。

**结论**：67 需要单独核对原图，不能直接当有效样本。

## 三、对我们的影响

### 1. 校准方法必须改

不能用"卡面 vs 模拟最终伤害"直接比。正确做法：

```
从卡面反推 (STAB × 克制 × buff)：
    factor = 卡面 / power

再用模拟器的最终伤害公式算：
    预测 = (atk/defn) × power × 0.9 × factor
    和卡面比就没意义了（factor 已经含在里面）
```

**更好的做法**：用卡面反推**当时的 buff 状态**，然后验证模拟器
在同样 buff 下的输出是否一致。

### 2. 卡面数字其实很有价值

它可以帮我们**推断对手的 buff**：

```
我方技能 power 已知
卡面读数 / (power × 我STAB) = 克制 × 我buff × 敌防buff
如果克制已知（对手精灵确定），就能反推 buff 状态
```

这对 PIMC 有用 —— 能知道对手当前叠了几层防。

### 3. 之前 S5 的"改善"可能是巧合

S5 把中位误差从 47.0% 降到 46.0%，但那个对比本身是错的
（比了两个不同的量）。**不应该用那个数字判断伤害公式的准确性。**
