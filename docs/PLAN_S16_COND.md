# S16 计划：条件型效果迷你引擎 + 全机制集成回归

> 原则：计划 → 实现 → 测试 → 基线核对 → commit → 文档。

## 探测结论

- 特性层 HP 阈值：0 条（3 条 gt/lt 特性是「强化等级<10」口径，语义
  需更多数据 → 延后）
- 技能层 HP 阈值：云行雨施（高于50%造成伤害+20%；低于50%受伤-20%）、
  入梦（低于50%全属性+20%）等——之前被 link 层如实 skip

## 实现：HP 阈值条件迷你引擎

1. **link_fx 解析**：`生命(高于|低于)X%` → dv["cond_mods"]：
   `{"hp_gt": 50, "dmg_dealt_pct": 0.2, "dmg_taken_pct": -0.2}`
   （"造成伤害+20%" → dealt；"受到伤害-20%" → taken）
2. **Battle 消费**：增益技使用后 pet._cond_mods = 规则（持续到换人
   清增益——与增益同生命周期，🟡 假设）
3. **calc_damage 消费**：
   - 攻方 _cond_mods.hp_gt 且 hp% > 阈值 → power ×(1+pct)
   - 守方 _cond_mods.hp_lt 且 hp% < 阈值 → dmg ×(1-taken_pct)
4. **入梦的全属性**：hp<50% → atk_buff/def_buff 临时 +0.2（出手时
   动态计算，进 calc_damage 的攻击增益合计——用 _cond_all 属性标记）

## 集成回归（test_s16_integration.py）

一个 6v6 战斗跑满 30 回合，双方配置覆盖 S8-S15 机制：
血脉+愿力强化+闪焰爆发+裁决+槽位锁+自动脱离+应对减益——
断言：不崩溃、事件含关键机制词、胜负合法。

## 基线风险

云行雨施/入梦不在基线队 → 零变化。

## 明确不做

- 强化等级阈值特性（恶龙的奢欲 3 条）——等级口径需实测数据
- 全属性（速度）动态化——速度增益已有独立通道，入梦只挂攻防
