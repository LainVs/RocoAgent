## 〇、一页速查

**胜负**：魔力 4 点打光即负；普通力竭 -1，诈死 -1、赎价/飓风 +1、御驾亲征 -4，**可叠加**。

**面板**：`round(round(种族×1.1 + 个体×0.55 + 10) × 性格 + 50)`，生命把 1.1→1.7、10→70、50→100、0.55→0.85。
个体在 PvP 统一 5 星 = 0–60，**了不起 = 恰好 3 项满**，其余 0。性格 ×1.2 / ×1.0 / ×0.9。

**伤害**：`round( round(攻/防 × 威力 × 0.9024) × 本系1.25 × 克制 × 其他 )` —— 基础伤害**先取整**。

**先手**：优先级 > 速度 > 随机；**应对成功 / 愿力触发覆盖以上三条**。

**技能三类**：攻击 → 状态 → 防御 → 攻击（循环克制）。**聚能是状态技，会被攻击打断。**

**思考顺序**（每回合照这个走）：

```
1. 这手能一击必杀吗？能 → 出（对面这回合被抹除）
2. 对面能一击必杀我吗？
     能 → 换人 / 防御 / 愿力（猜它出状态技）
     不能 → 继续比伤害
3. 我能量够下一手吗？不够 → 换人（绝不在有被打断风险时聚能）
4. 对面在铺场吗？在 → 优先打引擎部件（天气手 / 印记手）
5. 以上都不成立 → 出最大伤害
```

**三个死法**（我们踩过的）：能量耗尽还聚能、残血撤退换进更残的、把一次性精灵当站场主力。

## 一、胜负模型：不是打死 6 只，是打光 4 点魔力

```
每方 魔力 = 4 点
精灵力竭时结算：
    基础 -1
    + 该精灵特性修正（诈死 -1 / 赎价 +1 / 飓风 +1 / 御驾亲征 直接 -4）
    + 击杀者特性修正（赎价 +1）
    全部叠加，下限 0
任一方 <= 0 → 判负
```

**推论**：带"赎价"的精灵杀我们一只 = 我们 -2。**两次击杀就能结束一局**，
不是四次。所以"派一只上去试试"的真实成本是 2 点魔力。

## 二、回合结构：三类技能循环克制

```
攻击 → 状态 → 防御 → 攻击
```

- **攻击**：直接伤害，可以**打断**对面的状态技能
- **状态**：增益/减益/异常 —— **聚能也是状态技**，会被攻击打断
- **防御**：应对攻击，减伤 + 附带回血/反伤，**不能连续使用**

### 应对（Counter）：这是博弈的核心

每个技能可以带"应对攻击 / 应对防御 / 应对状态"：

```
猜对了 → 必定先手 + 触发应对效果
```

数据里有 **45+ 个技能**带应对，而且**应对类技能威力普遍很高**：

| 技能 | 威力 | 属性 | 应对效果 |
|---|---|---|---|
| 技巧打击 | 350 | 武 | — |
| 吹炎 | 340 | 龙 | 威力翻倍 |
| 爆冲 | 325 | 武 | — |
| 偷袭 | 255 | 普通 | 威力 ×3 |
| 突袭 | 210 | 普通 | 威力 ×3 |

**所以"出招顺序"不是纯拼速度**：

```
优先级 > 速度 > 随机
但 应对成功 会覆盖上面三条
```

### 许愿/愿力

```
愿力冲击：基础 100 伤害（属性由血脉决定）
若对面本回合使用「状态技能」→ 必定先手 + 伤害 ×2 = 200
```

这是**对"叠 buff 推队"的正面解药**：对面敢铺场，愿力就白嫖 200。

## 三、五个关键机制

| 机制 | 规则 | 影响 |
|---|---|---|
| **印记** | 一格正面 + 一格负面，换人不消失，可被清除 | 沙武队靠"正面印记 +1 能量/回合"实现永动 |
| **首领化** | 首领血脉 + 进化之力，**种族值提升 + 技能槽 4→7** | 不只是数值，是多 3 个选项 |
| **觉醒** | 60 级 5 星解锁，最多 5 次；本系强化 / 系别极化 / 系别钝化 | **本系倍率和克制倍率都不是常数** |
| **能量** | 上限 10，每回合回复；技能耗能 0–5 | 4–5 费技能只能打 2 发，之后必须聚能（且聚能会被打断） |
| **等级衰减** | 冥古龙：在场每回合 -10 级，**换下不重置** | 一次性弹药，只能留到必杀时用 |

## 四、数值体系（已实测校准，零误差）

### 面板

```
体力   = round( round(种族×1.7 + 个体×0.85 + 70) × 性格 + 100 )
其余项 = round( round(种族×1.1 + 个体×0.55 + 10) × 性格 + 50 )

个体：PvP 统一 5 星 → 刻度 0–60（0 星是 0–10，等比放大 6 倍）
      了不起的天分 = 恰好 3 项个体 60，其余 0
性格：×1.2 / ×1.0 / ×0.9
```

**校验样本（恶魔狼，六项零误差）**：种族 115/114/45/91/63/120 → 面板 417/218/104/160/129/260
（个体满三项：生命·物攻·速度；性格 +速度 −魔攻）

### 伤害

```
等级系数 L = (等级×45/100 + 10)/41      60 级 = 0.9024

基础伤害 = round( 攻击/防御 × 威力 × L )     ← 必须先取整
最终伤害 = round( 基础 × 本系 × 克制 × 其他 )

本系 1.25（实测，不是 1.5）
克制：单属性 ×2 / ×0.5；双属性相乘；配置档位 0.5 / 0.75 / 1.0 / 2.0
```

**校验样本**：吞噬150→142、火焰切割100火×2→380、蝙蝠65本系→154（三张全中）

### 先手

```
优先级（技能自带）> 速度面板 > 随机
应对成功 / 愿力触发 覆盖以上
```

## 五、高端对局的博弈结构

### 1. 每一回合都是矩阵博弈

```
收益 M[我i][对面j] 取决于：谁先手 + 是否一击必杀
若我先手且伤害 ≥ 对面血量 → 对面这一手被完全抹除
```

**"一击必杀"在数学上等于"白赚一个回合"** —— 这是摔炮队的根基。

### 2. 预判分两种，算法不同

| 情况 | 打法 | 算法 |
|---|---|---|
| 对手套路固定（如沙武队必开天气） | 针对它的固定手 | best response |
| 对手会变 | 最坏情况也不亏 | maximin / LP |

### 3. 三种队伍类型的胜负逻辑

| 类型 | 赢法 | 弱点 |
|---|---|---|
| **摔炮**（我们） | 每回合最大伤害，靠必杀滚雪球 | 打不穿就被拖死；能量耗尽是死穴 |
| **体系** | 铺场建引擎（天气+印记+buff），中期一波推 | 前 2–3 回合最脆弱 |
| **沙武（对手）** | 天气减耗→印记回能→0 费地刺循环 | 引擎启动前必须顶住 |

**关键判断**：

```
对面是"引擎型" → 我们的胜负窗口只有前 2–3 回合
   必须在这段时间打死引擎部件（天气手/印记手），否则必输
对面是"输出型" → 比速度和一击线
```

### 4. 沙武队实战拆解（已复盘）

```
它：开天气（地系减耗）→ 叠印记（+1 能量/回合）→ 0 费地刺循环
    地刺 = 攻击类 → 打断我们的状态技（含聚能）
我们：4–5 费技能 → 打两发没蓝 → 聚能被地刺打断 → 站着被打死
      最后琪后（高速高攻）克制恶魔狼（物防个体 0，脆）
```

**三条结论**：
1. 队伍配置错：摔炮不该带 4–5 费技能，应带 2–3 费稳定输出
2. 没蓝时**绝不能聚能**（会吃地刺），只能换人
3. 恶魔狼物防个体 0 → 遇到高攻速对手必被秒，不能当常规站场

## 九、常见体系队与打法风格

数据里 **80 个零费伤害技、162 个 1–2 费伤害技、101 个 4–5 费伤害技** ——
队伍风格的本质，就是选择吃哪一档费用的输出。

### ① 引擎型（沙武队）：天气 + 印记 + 0 费循环

```
开天气（地系减耗）→ 叠正面印记（+1 能量/回合）→ 0 费地刺无限循环
地刺是攻击类 → 顺手打断我方状态技（含聚能）
```

- **强**：第 3 回合后进入"无限输出 + 无限打断"，资源不衰减
- **弱**：前 2–3 回合最脆，引擎没起来就被打穿
- **针对**：集中火力打天气手/印记手；或用愿力（对面出状态技就吃 200）

### ② 滚雪球型（吸血肉盾）

```
蝙蝠（吸血 100%）/ 暗突袭（应对状态 → 威力翻倍 + 吸血 50%）
+ "获得敌方增益"类特性 → 越打血越多
```

- **强**：只要不被一击秒，血线一直在涨，耗掉对面的输出
- **弱**：怕一击必杀（吸血来不及生效就先死了）
- **针对**：把伤害堆到一击线以上

### ③ 超速爆发型（首领化 + 高速）

```
速度性格堆满 → 先手 → 首领化（种族值提升 + 技能槽 4→7）→ 一波带走
```

- **强**：先手 + 多 3 个技能选项
- **弱**：本身脆，被控/被秒就崩
- **针对**：算清速度线抢先手，或上克制属性的高速宠

### ④ 摔炮型（我们）

```
每回合取最大伤害，靠"一击必杀 = 抹除对面行动"滚雪球
```

- **强**：每手都能必杀时，等于每回合白赚一回合
- **弱**：打不穿就崩；4–5 费导致两发没蓝；被引擎型拖死
- **改造方向**：降费用（2–3 费），保留必杀判定

### ⑤ 异常/控制型

```
中毒 / 冻结 / 灼烧 / 麻痹 叠层 → 限制对面出手
```

- **强**：控住就是白赚回合
- **弱**：需要时间叠层，怕快攻

### ⑥ 反制型（功能位）

```
偷取增益 / 驱散印记（清线）/ 阻断（打断应对）
```

- 专门破坏上面几种体系的"引擎部件"
- **元博弈里反制队总会随主流出现 → 所以没有版本答案**

## 十、经济运营（能量）

### 收入

| 来源 | 数值 | 备注 |
|---|---|---|
| 自然回复 | 约 +1/回合 | 待实测 |
| 聚能 | +5 | **算状态技，会被攻击打断** |
| 特性 | 水系友善 +1/回合；地系友善 +4/3 回合；营养均衡 受治疗 +2 | 引擎型核心 |
| 印记 | +1/回合 | 沙武队靠这个 |
| 重载荷 | 上限 20，但**无法恢复能量** | 一次性爆发配置 |

### 支出

```
技能耗能 0–5，上限 10
4–5 费 → 只能打 2 发
2–3 费 → 能打 3–4 发
0 费    → 无限（80 个技能可选）
```

### 四条运营原则

1. **优先保"下一回合还能出手"** —— 打空能量等于送一个回合
2. **有被打断风险时绝不聚能** —— 对面有攻击类技能时，聚能=白挨一下
3. **0 费技能是经济核心** —— 它让"每回合都有输出"成立
4. **对面能量见底 = 我方进攻窗口**

### 与胜负的关系

```
摔炮 vs 引擎：谁的能量先耗尽谁输
我们 4–5 费 → 5 回合耗尽；对面 0 费 → 永不耗尽
→ 这个对局在第 3 回合就分出胜负了，不是第 10 回合
```

## 十一、高手是怎么理解这个游戏的

不是"打伤害"，是**同时管四种资源**：

| 资源 | 耗尽会发生什么 |
|---|---|
| **魔力 4 点** | 直接判负 |
| **能量** | 无法出手，只能聚能（还会被打断） |
| **印记** | 丢掉引擎（每回合回能/增伤） |
| **技能槽** | 选择面变窄（首领化 4→7 是反向） |

所以每一手的真实价值是：

```
价值 = 造成的伤害
     + 抢到的节奏（先手 = 白赚一回合）
     + 资源变化（能量 / 印记 / 魔力）
     - 暴露的信息（我的技能池被对面看到多少）
```

**高手和普通玩家的差别，往往不在算伤害，而在"这一手值不值一个回合"。**
