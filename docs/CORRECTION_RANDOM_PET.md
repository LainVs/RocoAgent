## 正确的做法

### 随机精灵的识别

`species` 表里 id 10000~10022 名字都是「随机精灵」。识别到这些 id
（或其形态）时，应该知道：**这只精灵的技能池是未知的，不能按可学池校验。**

但实测识别出的是**具体形态名**（棋绮后/棋祈督…），不是"随机精灵"。
说明游戏里随机精灵会变成**真实精灵的外形**，那它的技能池应该是
该形态的技能池 —— 从实测数据看正是如此（棋绮后的池命中影袭/岩脉崩毁/漫反射）。

**所以随机精灵换形态后，按新形态的池校验是可行的** —— 前提是身份
识别先对。这就回到了"身份必须准确"这个老问题，而 ONNX 在这个场景
是能工作的（日志里有 `PET -> 棋绮后 (ONNX ...)`）。

### 随机技能位（借用/取念/复写）

这个和随机精灵是两个独立问题：
- 随机精灵：精灵会变，但每个形态的技能池是确定的
- 借用/取念/复写：精灵不变，但该槽位的技能每回合随机

对后者，词表确实无法用"该精灵可学池"约束。但按描述：
- 借用 -> 己方队伍其他精灵的技能
- 取念 -> 敌方任意精灵的技能
- 复写 -> 自己未携带的技能（能耗-2）
