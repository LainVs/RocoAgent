# 悬浮窗配色对比度修复

**版本**：`ui-m80`
**日期**：2026-11-21
**前置**：`ui-m79`

---

## 一、问题（实测，非估算）

先纠正一个我一开始算错的模型：

```
❌ 错的假设：面板背景半透明、文字不透明
   -> 算出 ink-3 只有 1.83

✅ 实际实现（ui/app.js:937-952）：
   原生模式 CSS --alpha 固定 1.0，透明度走**整窗 alpha**
   （SetLayeredWindowAttributes）
   -> 文字和背景**一起**按同一比例变淡，对比度不会崩
```

按正确模型重算（三种典型游戏底色 × 窗口 alpha 0.78）：

### 深色主题

| token | 不透明 | 亮地面 | 暗阴影 | 中性灰 | 最坏 | 判定 |
|---|---|---|---|---|---|---|
| `--ink-0` | 15.10 | 8.15 | 9.62 | 9.09 | 8.15 | OK |
| `--ink-2` | 8.12 | 5.03 | 5.52 | 5.42 | 5.03 | OK |
| `--ink-3` | 3.72 | 2.80 | 2.82 | 2.90 | **2.80** | FAIL |
| `--accent` | 5.33 | 3.58 | 3.78 | 3.79 | 3.58 | 大字可 |
| `--kill` | 3.74 | 2.70 | 2.80 | 2.81 | **2.70** | FAIL |

### 浅色主题

| token | 不透明 | 亮地面 | 暗阴影 | 中性灰 | 最坏 | 判定 |
|---|---|---|---|---|---|---|
| `--ink-0` | 15.80 | 8.46 | 10.03 | 9.46 | 8.46 | OK |
| `--ink-2` | 6.71 | 4.18 | 5.15 | 4.63 | 4.18 | 大字可 |
| `--ink-3` | 3.26 | 2.48 | 2.86 | 2.65 | **2.48** | FAIL |
| `--accent` | 3.70 | 2.81 | 3.21 | 3.01 | **2.81** | FAIL |
| `--warn` | 3.09 | 2.42 | 2.74 | 2.57 | **2.42** | FAIL |

**`--ink-3` 两个主题都不达 AA（4.5），半透明下只剩 2.5~2.8。**

它承担的是 `.card-sub` / `.nav-label` / 空态提示这些**说明性文字** ——
用户最需要看清"为什么没有数据"的地方，恰恰最看不清。

---

## 二、决策

### 2.1 只改颜色值，不改结构

对比度不足是**取值问题**，不是布局问题。所以：

- 不动 `--alpha` 机制（上轮刚踩过"两层 alpha 相乘"的坑）
- 不动布局
- 只把不达标的 token 往"更远离背景色"的方向调

### 2.2 调整方向

**深色主题**（背景 #1F1E1D，往亮调）：
```
--ink-3   #7A776F -> 需要更亮
--kill    #C4553F -> 需要更亮（红调亮会偏粉，改用更亮的橙红）
```

**浅色主题**（背景 #FAF9F5，往暗调）：
```
--ink-3   #8E8A82 -> 需要更暗
--accent  #C96442 -> 需要更暗（暖珊瑚往砖红调）
--warn    #B8860B -> 需要更暗
```

### 2.3 目标

最坏情况（三种底色里最差的那个）达到 **4.5:1**。

不给"大字豁免"——`--ink-3` 的字号是 10~11px，属正文，不能豁免。

### 2.4 保持设计意图

调色不能变成"往黑白两端硬拉"，那会让界面失去 Claude 那种暖调。
所以约束：

- `--accent` 保持暖珊瑚/砖红（色相 15~25°）
- `--kill` 保持红（色相 0~10°）
- `--win` 保持绿（色相 130~150°）
- `--ink-3` 保持中性偏暖

---

## 三、实施

1. 写一个**调色求解器**：给定背景 + 目标对比度 + 色相约束，
   算出满足条件的最接近原色的值
2. 改 `ui/style.css` 的 token
3. 把对比度检查加进 `test_ui.py`（已有 `test_contrast` 段，扩展它）
4. 预览页 `ui/preview-minimal.html` 肉眼核对

---

## 四、验证

- 三种典型底色 × 两个主题，`--ink-3` 全部 >= 4.5
- `--accent` / `--kill` / `--win` / `--warn` 全部 >= 4.5
- 色相偏移不超过 ±15°（保持设计意图）
- `test_ui.py` 全过

---

## 五、不做

- **不改 `--alpha` 机制**（上轮踩过坑，两层 alpha 相乘会变灰雾）
- **不改字号**（那是另一个问题：11px 在 200% DPI 下是否够大）
- **不动布局**
