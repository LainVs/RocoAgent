## 二、已知机制清单（游戏内原文口径）

### 能量
- 上限 10，聚能 +5，战斗结束后不自动回复
- 能量不足时该技能放不出来

### 技能三分类（权威计数 562 技能）
- 攻击 345（物攻 190 / 魔攻 155）
- 状态 165
- 防御 52
- 另有 54 个 0 能耗、222 个 0 威力

### 应对
- 应对攻击 / 应对状态 / 应对防御 三类
- **应对成功：无视速度差，必定先手**，并触发应对效果
- 应对攻击成功后，携带的防御技能进入 1 回合冷却
- 先手度可叠加（先手 +1 共 4 个技能，-1 共 3 个）

### 异常状态（回合末结算）
- 中毒：3% 生命（毒系免疫）
- 灼烧：2% 生命，**层数衰减一半（向上取整）**（火系免疫）；1000 血封顶
- 冻结：5% 生命，若当前生命低于该比例则力竭（冰系免疫）
- 寄生：2% 生命，**从寄生来源吸取**（草系免疫）
- 萌化：退化为上一阶，种族资质下降，下场不消失

### 印记（换人不消失，新入场继承；正/负面各最多 1 种）
星陨（非幻系攻击触发，消耗全部层数造成幻系伤害）、中毒（回合末 3%）、湿润（全技能能耗 -1）、
减速（速度 -10）、萌芽（获得增益时额外 +1 层）、攻击（全技能威力 +10%）、
龙噬（释放 3 能耗技能后双攻 +30%）、蓄电（攻击技能迸发：威力 +10）、光合（回合末 +1 能量）、
蓄势（全攻击技能威力 +30%，能耗 +1）、棘刺（场上精灵离场后新入场者 -6% 生命）、
暗涌（新入场者获得随机 5 层属性减益）、风起（先手攻击时威力 +20%）、降灵（新入场者 -1 能量）

### 天气（全场唯一，有回合数上限）
- 雨天：双方水系技能威力 **+50% 或 +75%（两处来源冲突，待定）**
- 沙暴：双方地系技能**能耗减半**
- 暴风雪：双方每回合末获得 **2 层冻结**
- 雷鸣：双方每回合末获得 **1 层引电**

### 场地
- 亲和【强】+50 速、亲和【弱】+25、抵触【弱】-25、抵触【强】-50
- 「无畏」特长把抵触转亲和

### 胜负
- **4 格生命制（魔力）**：每倒下一只 -1 魔力，归 0 判负

### 其他
- 换人：结束本回合，**清除增益/减益**，印记保留
- 技能关键词：先手/迸发/蓄力/脱离/迅捷/打断/吸血/传动/巧变/选择/过载/奉献/禁足/返场/积蓄
- 血脉 / 愿力冲击 / 首领化：未建模
