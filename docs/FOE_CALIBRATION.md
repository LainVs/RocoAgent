# S19 实战伤害校准表（2026-11-23）

> 数据源：logs/turns.jsonl 40 个 team_db 观测（卡牌预览 V + foe_pct 差分）。
> 脚本：`scripts/foe_calibration.py` → `data/foe_calibration.json`。

## 方法

```
live_dmg = (foe_pct[t] - foe_pct[t+1]) / 100 × foe_max_hp_sim
k = live_dmg / V          （V = 游戏卡牌预览伤害）
按 foe 聚合中位数 → data/foe_calibration.json
```

foe_max_hp_sim = species 种族 hp @60 级（对方面板未知，无法分离
max_hp 与减伤——只能校准乘积，即“有效承伤系数”）。

## 精度

- 总体：n=40，**残差中位 0%**，p75 29%
- 对比 S18 静态对账（MAE 87 / 相对 44.8%）：per-foe 校准后残差
  中位数降到 0——**机器人预测伤害 × k(对手) ≈ 实盘**
- 污染观测（翠顶夫人/鸭吉吉）：治疗回合误判或多次伤害差分错位，
  n≥3 的对手残差已显著收敛

## 使用（机器人侧）

```python
import json
calib = json.load(open("data/foe_calibration.json"))
k = calib.get(foe_name, {}).get("k_median", 1.0)
predicted = card_preview * k      # 修正后 ≈ 实盘
```

## 局限

- k 是乘积校准（max_hp × 减伤 × 防御增益），无法分离来源
- 单样本对手的 k=单比值，无置信度
- 治疗回合污染：已过滤 pct 上升，但「先受伤后治疗」的回合仍可能
  低估 live_dmg → k 偏低（翠顶夫人的 695% 残差即此类）
