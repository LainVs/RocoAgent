# S9 计划：其余 4 个共鸣魔法（血脉魔法）

> 原则：每批 = 计划 → 实现 → 测试 → 基线核对 → commit → 文档。
> 权威源：rocoduel.com/zh/dex/magic（国服第 5 赛季数据）。

## 官方原文（rocoduel，2026-11-23 抓取）

| 魔法 | 原文 | 目标条件 |
|---|---|---|
| 进化之力 | 对首领血脉的精灵使用，本场战斗中进化，部分激活远古血脉 | 首领血脉 |
| 愿力强化 | 使用后技能栏第一个技能本回合被替换为【愿力冲击】，属性与血脉一致。持续1回合，CD3，每场2次 | 任意血脉（首领除外）✅ S8 已实现 |
| 光合治愈 | 对草系或草血脉的精灵使用，恢复精灵 50% 生命 | 草系或草血脉 |
| 闪焰爆发 | 对火系或火血脉的精灵使用，本回合技能威力提升 150% | 火系或火血脉 |
| 节流术 | 对水系或水血脉的精灵使用，本回合技能不扣除能耗 | 水系或水血脉 |

## 语义假设（🟡 无法从公开源确认，按最合理建模并标注）

1. **行动模型**：愿力强化的原文「本回合被替换…持续1回合」说明施放魔法的
   当回合精灵**仍然出手**。三个新魔法同模型：施放 → 本回合增益/回复生效，
   精灵照常出手。`step("magic", payload)` 的 payload = 精灵本回合用的技能下标
   （愿力强化特殊：payload 忽略，固定第一格）。
2. **CD/次数**：只有愿力强化有明确 CD3/2次。其余三个按队伍魔法对称性
   建模为同样 CD3/2 次（🟡 假设，若实测不同只改常量）。
3. **目标校验**：施放时当前出战精灵必须满足条件（X系 或 X血脉）。
   火系判断 = "火" in types 或 bloodline=="火"。
4. **光合治愈 50%**：按 max_hp 计算（与中毒 3% 同口径）。

## 实现

- `simulator.py`：
  - `MAGIC_SPELLS` 表：{"光合治愈": "grass_heal", "闪焰爆发": "fire_power",
    "节流术": "water_free", "愿力强化": "yuanli"}
  - `step("magic")`：按 team_magic[side] 分派
    - grass_heal：立刻回 50% max_hp（事件播报），精灵用 payload 技能出手
    - fire_power：本回合威力 +150%（复用 counter_power_bonus 通道）
    - water_free：本回合免能耗
    - 目标不满足 → 动作落空（播报，不扣次数）
  - acts 出手：kind=="magic" 时 mv = skill_a（payload 指向的技能）
- `manual_battle.py`：act({"kind":"magic"}) 分派 + state().magic 显示
  （name/usable）；UI 侧零改动可用。

## 测试（src/test_s9_magic.py）

- 光合治愈：草系精灵回 50%；非草 → 落空不扣次数
- 闪焰爆发：火系出手威力 +150%（对照伤害数字）；非火 → 落空
- 节流术：水系出手不扣能耗；非水 → 落空
- 共有：CD3/2次 + 次数耗尽提示

## 基线风险

基线队伍不带这三个魔法（team_magic 默认 None）→ 基线零变化。
