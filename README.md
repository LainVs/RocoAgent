# RocoAgent — 洛克王国世界 PvP 自动对战系统

> 立项：2026-11-17
> 目标：打进人类排位前 50%
> 特点：分层架构，全流程可记录，支持自我优化

---

## 一、设计原则

```
① 感知与决策分离
   感知层只负责"把屏幕变成数字"，不掺任何判断
   决策层只吃结构化 state，不碰像素

② 每一回合都落盘
   state + action + 结果 → logs/，这是自优化的唯一原料

③ 决策可回放
   给定同一条日志，能重算出当时的决策，便于复盘

④ 出招不经过大模型
   实时回路全是本地代码，延迟 < 0.5 秒
   大模型只负责：写代码、定策略、复盘日志
```

## 二、分层架构

```
┌─────────────────────────────────────────┐
│  perception  截图 → state.json          │
│   我方：精灵/HP/能量/技能(已知)          │
│   敌方：精灵/HP%/属性/强化图标           │
│   场上：天气/印记/回合数                 │
└────────────────┬────────────────────────┘
                 ↓ state
┌─────────────────────────────────────────┐
│  policy  state → action                 │
│   规则层：能秒？会被秒？能量够？          │
│   计算层：伤害区间（含属性克制）          │
│   搜索层：2~3 回合的换人/出招推演        │
└────────────────┬────────────────────────┘
                 ↓ action
┌─────────────────────────────────────────┐
│  actuator  action → ESP32 按键           │
│   BLE 指令，硬件 HID，反作弊安全          │
└─────────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────────┐
│  logger  每回合落盘 → logs/*.jsonl       │
└─────────────────────────────────────────┘
```

## 五、自优化机制

```
第一层  规则参数可调
        例如「残血换人阈值」「能量保留阈值」
        用日志回放做网格搜索，找胜率最高的参数组

第二层  对局统计
        每个决策点记录：局面特征 → 选择 → 结果
        统计「哪种选择在同类局面下胜率高」

第三层  （后期）小模型
        用日志训练一个分类器，替代规则打分
        输入 state 向量，输出 4+2 个动作的概率
```

## 六、路线图

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 | 项目骨架 + 截图/区域校准 | 能稳定截到技能栏 |
| P1 | 感知层：我方 + 敌方基础状态 | state.json 能正确反映战况 |
| P2 | 伤害计算 + 规则决策 | 不犯「打被抵抗技能」这种错 |
| P3 | 全自动对战 + 日志 | 能连续打完一整局不用人管 |
| P4 | 参数搜索自优化 | 胜率比 P2 提升 |
| P5 | 冲前 50% | 排位分段验证 |
